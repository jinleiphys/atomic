5.2 精细结构与塞曼效应¶

光谱线的精细分裂¶

如果用一台普通的光谱仪观察钠的发射光谱，最醒目的特征无疑是那条明亮的黄色 D 线，波长大约在 589 nm 附近。但当人们换用分辨率更高的仪器仔细审视这条看似单一的谱线时，会发现它其实并不是一条线，而是两条非常接近的谱线：D1D_1D1​ 线的波长为 589.592 nm，D2D_2D2​ 线的波长为 588.995 nm。两者的波长差仅仅 0.597 nm，但它们确确实实是两条独立的谱线，各自具有明确的频率和强度。这种现象并非钠原子所独有——所有碱金属原子的光谱中都可以观察到类似的双线结构，而在氢原子光谱中同样存在，只是分裂的幅度更加微小。这种谱线的细微分裂就是所谓的精细结构(fine structure)。

精细结构的物理根源在于自旋-轨道耦合(spin-orbit coupling)。要理解这一耦合的本质，可以从电子的视角出发来思考。在原子中，电子绕原子核运动(或者更精确地说，电子的概率分布围绕原子核展开)。如果我们暂时切换到电子的参考系，从电子"看来"，带正电荷的原子核正在围绕自己做运动。一个运动的电荷等价于一个电流，而电流会在周围空间中产生磁场。因此，在电子的参考系中，它"感受"到一个由原子核的相对运动所产生的内部磁场 Bint\mathbf{B}_{\text{int}}Bint​。电子自身携带的自旋磁矩 μs\boldsymbol{\mu}_sμs​ 在这个内部磁场中会获得一份额外的势能，这便是自旋-轨道耦合的起源。这一相互作用的哈密顿量可以写为：

HSO=−μs⋅Bint∝L⋅SH_{SO} = -\boldsymbol{\mu}_s \cdot \mathbf{B}_{\text{int}} \propto \mathbf{L} \cdot \mathbf{S}HSO​=−μs​⋅Bint​∝L⋅S
(1)

也就是说，自旋-轨道耦合能正比于轨道角动量 L\mathbf{L}L 和自旋角动量 S\mathbf{S}S 的点积。当自旋与轨道角动量的方向较为一致(即两者的夹角较小)时，L⋅S\mathbf{L} \cdot \mathbf{S}L⋅S 为正值，耦合能取一个值；当两者方向较为相反时，L⋅S\mathbf{L} \cdot \mathbf{S}L⋅S 为负值，耦合能取另一个值。这就导致原本简并的能级分裂为两个。

需要特别指出的是，上述从"电子参考系"出发的推导虽然直觉上非常清晰，但在严格的意义上是一个近似。电子的参考系是一个加速参考系(因为电子在做曲线运动)，直接在这个参考系中应用电磁学定律会引入一个额外的修正因子，即所谓的托马斯进动(Thomas precession)。托马斯在 1926 年指出，由于狭义相对论中加速参考系的非平凡变换性质，简单的参考系变换会高估自旋-轨道耦合的大小恰好两倍，托马斯进动修正因子为 1/21/21/2。因此，自旋-轨道耦合从本质上是一个相对论效应，它的完整推导需要狄拉克方程或至少需要考虑狭义相对论的运动学效应。

由于自旋-轨道耦合使得 L\mathbf{L}L 和 S\mathbf{S}S 不再各自独立守恒，我们需要引入一个新的量——总角动量：

J=L+S\mathbf{J} = \mathbf{L} + \mathbf{S}J=L+S
(2)

与 L\mathbf{L}L 和 S\mathbf{S}S 一样，J\mathbf{J}J 的大小也是量子化的。总角动量量子数 jjj 可以取的值由角动量耦合的规则决定：

j=l+s=l+12或j=l−s=l−12(l≥1)j = l + s = l + \frac{1}{2} \quad \text{或} \quad j = l - s = l - \frac{1}{2} \quad (l \geq 1)j=l+s=l+21​或j=l−s=l−21​(l≥1)
(3)

对于 l=0l = 0l=0 的情况(即 sss 态电子)，自旋与轨道没有耦合的"伙伴"，只有 j=1/2j = 1/2j=1/2 这一种可能，因此不发生精细分裂。而对于 l≥1l \geq 1l≥1 的任何态，每个能级都一分为二，对应于 j=l+1/2j = l + 1/2j=l+1/2 和 j=l−1/2j = l - 1/2j=l−1/2 两个子能级。

回到钠 D 线的例子：钠原子的 3p3p3p 态(l=1l = 1l=1)在自旋-轨道耦合的作用下分裂为 3p3/23p_{3/2}3p3/2​(j=3/2j = 3/2j=3/2)和 3p1/23p_{1/2}3p1/2​(j=1/2j = 1/2j=1/2)两个子能级，而 3s3s3s 态(l=0l = 0l=0)则不分裂，只有 3s1/23s_{1/2}3s1/2​。从 3p3p3p 到 3s3s3s 的跃迁因此产生两条谱线而非一条：从 3p3/23p_{3/2}3p3/2​ 到 3s1/23s_{1/2}3s1/2​ 的跃迁给出 D2D_2D2​ 线，从 3p1/23p_{1/2}3p1/2​ 到 3s1/23s_{1/2}3s1/2​ 的跃迁给出 D1D_1D1​ 线。

3p3/2→3s1/2:D2 线3p_{3/2} \to 3s_{1/2}: \quad D_2 \text{ 线}3p3/2​→3s1/2​:D2​ 线
(4)
3p1/2→3s1/2:D1 线3p_{1/2} \to 3s_{1/2}: \quad D_1 \text{ 线}3p1/2​→3s1/2​:D1​ 线
(5)

精细结构的故事还不止于此。当原子被置于外部磁场 B\mathbf{B}B 中时，能级会发生进一步的分裂，这就是以荷兰物理学家彼得·塞曼(Pieter Zeeman)命名的塞曼效应(Zeeman effect)。塞曼效应的发现有着一段曲折的历史。1896 年，塞曼在莱顿大学观察到，当光源被放置在强磁铁的磁极之间时，钠 D 线出现了明显的展宽。他的导师洛伦兹(Hendrik Lorentz)迅速用经典电子理论给出了解释：带电粒子在磁场中的运动会发生进动，导致辐射频率发生移动。洛伦兹的理论预言每条谱线在磁场中分裂为三条——这就是后来所说的"正常塞曼效应"。塞曼和洛伦兹因此发现共同获得了 1902 年的诺贝尔物理学奖。

然而，当实验物理学家们将更多的谱线放在磁场中检验时，情况变得复杂了。大多数谱线的分裂模式并不遵循洛伦兹的"三线"预言，而是呈现出更加复杂的多线结构。这些"不听话"的分裂模式被称为"反常塞曼效应"(anomalous Zeeman effect)，在此后的二十多年里一直是理论物理学的一个谜团。直到电子自旋被发现、量子力学建立起来之后，人们才终于理解，所谓的"反常"塞曼效应其实才是一般情况，而洛伦兹预言的"正常"效应反而是特殊情况——它只在原子总自旋为零(S=0S = 0S=0)时才会出现。物理学的"正常"与"反常"的命名，有时恰好与事物的普遍性相反。

在外磁场中，总角动量 J\mathbf{J}J 的 zzz 分量 mjm_jmj​ 的不同取值对应不同的能量。塞曼分裂的能量为：

ΔE=gjmjμBB\Delta E = g_j m_j \mu_B BΔE=gj​mj​μB​B
(6)

其中 gjg_jgj​ 是朗德 ggg 因子：

gj=1+j(j+1)+s(s+1)−l(l+1)2j(j+1)g_j = 1 + \frac{j(j+1) + s(s+1) - l(l+1)}{2j(j+1)}gj​=1+2j(j+1)j(j+1)+s(s+1)−l(l+1)​
(7)

每个具有确定 jjj 值的能级在磁场中分裂为 2j+12j+12j+1 个子能级，对应 mjm_jmj​ 从 −j-j−j 到 +j+j+j 的 2j+12j+12j+1 个取值。当原子总自旋 S=0S = 0S=0 时，gj=1g_j = 1gj​=1，所有能级的分裂间距完全均匀，跃迁选择定则使得每条谱线恰好分裂为三条，这就是正常塞曼效应。当 S≠0S \neq 0S=0 时(也就是自旋参与耦合的一般情况)，gjg_jgj​ 的值依赖于 jjj、lll、sss 的具体组合，上下能级的分裂间距不再简单相等，跃迁产生的谱线数目和排列方式变得复杂多样，这就是反常塞曼效应。

硅基视角：微扰理论，给系统打补丁¶

从软件工程的角度来看，氢原子能级结构的发展史就像一个软件产品的版本迭代过程。最初的 v1.0 版本是玻尔模型(第二章的内容)，它的核心代码(主程序)是库仑势 V(r)=−e2/rV(r) = -e^2/rV(r)=−e2/r，输出结果是 En=−13.6/n2E_n = -13.6/n^2En​=−13.6/n2 eV 的能级公式，精度大约在 10-1 eV 的量级上。升级到 v2.0 之后(第四章的薛定谔方程)，主程序的物理内核没有改变(仍然是非相对论的量子力学配合同样的库仑势)，能级公式也与玻尔模型给出的一样，但系统增加了一个关键的新产出——完整而精确的波函数，精度仍然在 10-1 eV 的水平。到了 v2.1 版本(本章的精细结构补丁)，系统安装了三个补丁包：自旋-轨道耦合项 HSO∼L⋅SH_{SO} \sim \mathbf{L} \cdot \mathbf{S}HSO​∼L⋅S、相对论动能修正以及达尔文项。这些补丁使得能级公式变为 Enj=En+ΔE(j)E_{nj} = E_n + \Delta E(j)Enj​=En​+ΔE(j)，其中能量修正依赖于总角动量量子数 jjj，系统精度提升到了 10-5 eV。进一步安装 v2.2 补丁(塞曼效应)之后，外磁场耦合项 −μ⋅B-\boldsymbol{\mu} \cdot \mathbf{B}−μ⋅B 被加入，能级公式扩展为 Enjm=Enj+gjmjμBBE_{njm} = E_{nj} + g_j m_j \mu_B BEnjm​=Enj​+gj​mj​μB​B，精度取决于外场强度，可以达到 10-6 eV 的水平。

这种"在已有结果上逐步叠加小修正"的方法论，在量子力学中被系统化为微扰理论(perturbation theory)。微扰理论的算法逻辑非常清晰：首先，求解无微扰系统(也就是"主程序")的精确解，得到零阶波函数 ψn(0)\psi_n^{(0)}ψn(0)​ 和零阶能量 En(0)E_n^{(0)}En(0)​。然后，将微扰项 H′H'H′(也就是"补丁")视为一个相对于主程序哈密顿量而言的小量。最后，逐阶地计算能量和波函数的修正。

En(1)=⟨ψn(0)∣H′∣ψn(0)⟩E_n^{(1)} = \langle \psi_n^{(0)} | H' | \psi_n^{(0)} \rangleEn(1)​=⟨ψn(0)​∣H′∣ψn(0)​⟩

AI Workshop：塞曼效应能级分裂¶

import numpy as np
import matplotlib.pyplot as plt

def lande_g(j, l, s=0.5):
    """计算朗德 g 因子"""
    if j == 0:
        return 0
    return 1 + (j*(j+1) + s*(s+1) - l*(l+1)) / (2*j*(j+1))

def zeeman_splitting(n, l, B_range):
    """
    计算给定 (n,l) 态在外磁场中的塞曼分裂
    返回各子能级的能量 (相对于无场能量)
    """
    s = 0.5
    mu_B = 5.788e-5  # eV/T

    levels = {}
    for j in [l + s, abs(l - s)]:
        if j < 0:
            continue
        g = lande_g(j, l)
        for mj in np.arange(-j, j+1, 1):
            label = f"j={j:.0f}/2, mj={mj:+.0f}/2" if j % 1 else f"j={j:.0f}, mj={mj:+.0f}"
            # 实际使用半整数
            levels[(j, mj)] = g * mj * mu_B * B_range

    return levels

# 钠 D 线: 3p → 3s 跃迁在磁场中的分裂
fig, axes = plt.subplots(1, 2, figsize=(14, 8))
B = np.linspace(0, 2, 100)  # 磁场 0-2 T

# 3p 态 (l=1): j=3/2 和 j=1/2
ax = axes[0]
ax.set_title('3p 态的塞曼分裂')
s = 0.5
mu_B = 5.788e-5  # eV/T

for j in [1.5, 0.5]:
    g = lande_g(j, l=1)
    for mj in np.arange(-j, j+1, 1):
        E_offset = 0 if j == 1.5 else -0.002  # 自旋-轨道分裂 (示意)
        E = E_offset + g * mj * mu_B * B
        label = f'j={j}, $m_j$={mj:+.1f}'
        color = 'blue' if j == 1.5 else 'red'
        ax.plot(B, E * 1000, color=color, label=label)  # meV

ax.set_xlabel('磁场 B (T)')
ax.set_ylabel('能量偏移 (meV)')
ax.legend(fontsize=7, ncol=2)
ax.grid(True, alpha=0.3)

# 3s 态 (l=0): 只有 j=1/2
ax = axes[1]
ax.set_title('3s 态的塞曼分裂')
g = lande_g(0.5, l=0)
for mj in [-0.5, 0.5]:
    E = g * mj * mu_B * B
    ax.plot(B, E * 1000, 'green', label=f'j=1/2, $m_j$={mj:+.1f}')

ax.set_xlabel('磁场 B (T)')
ax.set_ylabel('能量偏移 (meV)')
ax.legend(fontsize=9)
ax.grid(True, alpha=0.3)

plt.suptitle('钠 D 线的塞曼效应', fontsize=14)
plt.tight_layout()
plt.savefig('zeeman_effect.png', dpi=150)
plt.show()

# 打印朗德 g 因子
print("朗德 g 因子:")
print(f"  3s (l=0, j=1/2): g = {lande_g(0.5, 0):.3f}")
print(f"  3p (l=1, j=1/2): g = {lande_g(0.5, 1):.3f}")
print(f"  3p (l=1, j=3/2): g = {lande_g(1.5, 1):.3f}")
