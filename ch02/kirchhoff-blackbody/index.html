2.1 基尔霍夫热辐射定律与黑体辐射¶

炉火中的物理学¶

任何温度高于绝对零度的物体都会向外辐射电磁波，这就是热辐射。日常生活中的例子比比皆是：烧红的铁块发出暗红色的光，温度更高时变为橙黄色，电炉丝在通电后先变红再变亮白。太阳表面温度约 5800 K，它辐射的电磁波覆盖了从紫外到红外的宽广波段，峰值恰好落在可见光区域，这并非巧合，因为人类的眼睛正是在漫长的演化过程中适应了太阳辐射的峰值波段。热辐射是一种极为普遍的现象，它不依赖于物体的化学组成或表面状态，而只与温度有关。理解热辐射的规律，不仅是 19 世纪物理学面临的重大理论挑战，也是工业革命背景下钢铁冶炼、玻璃制造等高温工艺对温度精确测量的迫切需求。

1859 年，德国物理学家古斯塔夫·基尔霍夫(Gustav Robert Kirchhoff)提出了一条关于热辐射的普遍定律，这条定律的简洁与深刻令人惊叹 Kirchhoff (1860)。基尔霍夫考虑的问题是：不同物体在同一温度下辐射和吸收电磁波的能力各不相同，铜和碳、玻璃和钢铁，它们的辐射本领(单位面积单位时间辐射的能量)和吸收本领(入射辐射被吸收的比例)显然不同。但基尔霍夫证明了一个惊人的结论：对于任何物体，在热平衡状态下，其辐射本领 ε(ν,T)\varepsilon(\nu, T)ε(ν,T) 与吸收本领 α(ν,T)\alpha(\nu, T)α(ν,T) 之比是一个只依赖于频率 ν\nuν 和温度 TTT 的普适函数，与物体的材质、形状、大小完全无关：

ε(ν,T)α(ν,T)=J(ν,T)\frac{\varepsilon(\nu, T)}{\alpha(\nu, T)} = J(\nu, T)α(ν,T)ε(ν,T)​=J(ν,T)
(1)

这个结论的证明只需要热力学第二定律。基尔霍夫的论证如下：设想两个不同材质的物体被封闭在一个绝热容器中，经过足够长的时间后达到热平衡，温度处处相同。此时每个物体辐射出去的能量必须等于它吸收的能量(否则温度会改变，违反热平衡)。如果两个物体的 ε/α\varepsilon/\alphaε/α 之比不同，那么 ε/α\varepsilon/\alphaε/α 较大的物体会净辐射能量给另一个物体，导致一个变冷、一个变热，而这种自发的温差产生违反了热力学第二定律。因此，ε/α\varepsilon/\alphaε/α 必须是普适的。

基尔霍夫定律的深刻之处在于它定义了一个理想化的极限情形。如果一个物体能够完全吸收所有入射的辐射，即 α(ν,T)=1\alpha(\nu, T) = 1α(ν,T)=1 对所有频率成立，那么这个物体被称为"黑体"(blackbody)，因为它不反射任何光线，在常温下看起来是完全黑色的。对于黑体，基尔霍夫定律简化为 ε(ν,T)=J(ν,T)\varepsilon(\nu, T) = J(\nu, T)ε(ν,T)=J(ν,T)，也就是说，黑体的辐射本领就等于那个普适函数本身。换言之，黑体辐射谱是自然界中最基本的辐射谱，它代表了热平衡态下电磁辐射的"标准形态"，不携带任何关于辐射体材质的信息，仅由温度决定。任何偏离黑体辐射谱的辐射，都意味着系统偏离了热平衡。

基尔霍夫敏锐地意识到，确定这个普适函数 J(ν,T)J(\nu, T)J(ν,T) 的具体形式是物理学面临的最重要的问题之一。他本人无法给出这个函数，但他的定律明确指出了问题的方向：物理学家需要找到一个关于频率和温度的函数，它完全由基本物理常数决定，不含任何材料参数。这个函数的确定将揭示热辐射的本质机制。从 1860 年代到 1900 年，整整四十年间，一代又一代物理学家投身于这个问题，逐步逼近最终的答案。

从经验定律到紫外灾变¶

寻找黑体辐射普适函数的历程遵循了一条典型的物理学路径：先从实验中提取经验定律，再用理论来推导和统一这些经验定律。

第一个重要的经验结果来自斯特藩(Josef Stefan)。1879 年，斯特藩根据廷德尔(Tyndall)关于铂丝辐射的实验数据，发现黑体辐射的总功率(对所有频率积分)与温度的四次方成正比 Stefan (1879)：

P=σT4P = \sigma T^4P=σT4
(2)

其中 σ=5.67×10−8 W m−2K−4\sigma = 5.67 \times 10^{-8} \text{ W m}^{-2}\text{K}^{-4}σ=5.67×10−8 W m−2K−4 是斯特藩-玻尔兹曼常数。1884 年，玻尔兹曼从热力学出发，用辐射压的概念严格推导了这一关系，赋予了它理论基础。斯特藩-玻尔兹曼定律告诉我们黑体辐射的"总量"如何随温度变化，但没有告诉我们辐射能量在不同频率之间如何分配。

第二个关键突破来自维恩(Wilhelm Wien)。1893 年，维恩利用热力学和绝热过程的性质，推导出了著名的维恩位移定律 Wien (1893)：黑体辐射谱的峰值波长 λmax⁡\lambda_{\max}λmax​ 与温度 TTT 成反比：

λmax⁡T=b\lambda_{\max} T = bλmax​T=b
(3)

其中 b=2.898×10−3 m⋅Kb = 2.898 \times 10^{-3} \text{ m}\cdot\text{K}b=2.898×10−3 m⋅K 是维恩位移常数。这个定律解释了一个日常经验：随着温度升高，发光体的颜色从暗红到橙黄到白色再到蓝白色，这是因为辐射峰值向短波长(高频)方向移动。维恩位移定律在天文学中有着直接的应用。冬季夜空中猎户座的两颗亮星提供了一个绝佳的例子：参宿四(Betelgeuse)呈现偏红的颜色，而参宿七(Rigel)呈现偏蓝白的颜色。如果把它们近似看作黑体，由于蓝光的波长短于红光(λblue<λred\lambda_{\text{blue}} < \lambda_{\text{red}}λblue​<λred​)，维恩位移定律立即告诉我们 Tblue>TredT_{\text{blue}} > T_{\text{red}}Tblue​>Tred​，即参宿七的表面温度高于参宿四。实际测量表明参宿四的表面温度约 3500 K，而参宿七约 12000 K，与这一简单推断完全一致。维恩还提出了一个黑体辐射谱的具体函数形式，在高频区与实验符合得很好，但在低频区出现了偏差。

1900 年前后，柏林帝国物理技术研究院的实验物理学家们(鲁本斯、库尔鲍姆等人)对黑体辐射进行了极其精密的测量。他们使用的"黑体"是一个带小孔的加热空腔，从小孔逸出的辐射非常接近理想黑体辐射。实验结果清楚地表明：维恩公式在短波长(高频)区符合得很好，但在长波长(低频)区系统性地偏低。

与此同时，瑞利(Lord Rayleigh)和金斯(James Jeans)从经典物理出发推导出了另一个公式 Rayleigh (1900)。他们的推导基于两个无可置疑的经典原理：腔体中的电磁波可以分解为一系列驻波模式，每个模式的数目可以用经典电磁学精确计算；根据经典统计力学的能量均分定理，在热平衡时每个模式分配到 kBTk_B TkB​T 的平均能量。让我们详细跟踪这个推导，因为正是在这个无懈可击的推导中，经典物理暴露了自己的致命缺陷。

普朗克的量子假设¶

1900 年 10 月 19 日，马克斯·普朗克(Max Planck)在柏林物理学会的一次会议上提出了一个新的辐射公式，这个公式在所有频率范围内都与实验精确吻合：

u(ν,T)=8πhν3c31ehν/kBT−1u(\nu, T) = \frac{8\pi h\nu^3}{c^3} \frac{1}{e^{h\nu / k_B T} - 1}u(ν,T)=c38πhν3​ehν/kB​T−11​
(8)

其中 h=6.626×10−34 J⋅sh = 6.626 \times 10^{-34} \text{ J}\cdot\text{s}h=6.626×10−34 J⋅s 是一个全新的基本常数，后来被称为普朗克常数。这个公式在低频极限(hν≪kBTh\nu \ll k_BThν≪kB​T)下退化为瑞利-金斯公式，在高频极限(hν≫kBTh\nu \gg k_BThν≫kB​T)下退化为维恩公式，完美地统一了两个经验定律。

然而，普朗克在推导这个公式时被迫做出了一个革命性的假设：组成空腔壁的微观振子的能量不能连续取值，而只能取 ε=nhν\varepsilon = nh\nuε=nhν (n=0,1,2,3,…n = 0, 1, 2, 3, \ldotsn=0,1,2,3,…) 的离散值 Planck (1901)。也就是说，频率为 ν\nuν 的振子只能以 hνh\nuhν 为单位吸收或释放能量。这个假设与经典物理完全矛盾。在经典力学中，一个谐振子的能量可以从零到无穷大连续取值，没有任何理由要求能量必须是某个最小单元的整数倍。普朗克本人对这个假设也深感不安。他最初试图将量子化视为一种数学技巧，一种在推导过程中引入的辅助手段，希望最终能在经典框架内找到解释。但无论他怎么尝试，都无法在不引入能量量子化的情况下得到正确的辐射公式。

理解普朗克假设为什么能解决紫外灾变，关键在于认识到量子化如何改变了高频模式的行为。在经典理论中，无论频率多高，每个模式都分配到 kBTk_BTkB​T 的平均能量。但在普朗克的理论中，频率为 ν\nuν 的模式要获得一份能量，至少需要 hνh\nuhν。当 hν≫kBTh\nu \gg k_BThν≫kB​T 时，热运动提供的能量远不足以激发哪怕一个量子，这些高频模式实际上被"冻结"了，对辐射几乎没有贡献。这就像一台自动售货机只接受整数金额的纸币：如果一瓶水的价格是100元而你只有5元，那么你一瓶水也买不到，即使经典理论告诉你5元的"平均购买力"应该让你买到0.05瓶水。量子化切断了高频模式对能量的无底洞式的索取，从而消除了紫外灾变。

普朗克公式的提出标志着量子论的诞生，尽管普朗克本人并没有完全意识到自己所做之事的革命性。在接下来的几年里，爱因斯坦将量子化思想从振子推广到了光本身(光量子假说，1905 年)，而玻尔则将它应用于原子结构(1913 年)。但这一切的起点，都是一个加热空腔中的电磁辐射所呈现的那条不起眼的光谱曲线。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Heiti TC', 'Noto Sans CJK SC', 'SimHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False

# 物理常数
h = 6.62607015e-34   # 普朗克常数 (J·s, SI精确定义)
c = 299792458.0      # 光速 (m/s, SI精确定义)
kB = 1.380649e-23    # 玻尔兹曼常数 (J/K, SI精确定义)

def planck(lam, T):
    """普朗克黑体辐射公式 (单位: W·m⁻²·m⁻¹·sr⁻¹)"""
    return (2 * h * c**2 / lam**5) / (np.exp(h * c / (lam * kB * T)) - 1)

def rayleigh_jeans(lam, T):
    """瑞利-金斯公式"""
    return 2 * c * kB * T / lam**4

def wien_approx(lam, T):
    """维恩近似公式"""
    return (2 * h * c**2 / lam**5) * np.exp(-h * c / (lam * kB * T))

# 波长范围 (m)
lam = np.linspace(1e-7, 3e-6, 1000)

fig, axes = plt.subplots(1, 2, figsize=(13, 5))

# 左图：不同温度下的普朗克辐射谱
temperatures = [3000, 4000, 5000, 6000]
colors = ['#d62728', '#ff7f0e', '#2ca02c', '#1f77b4']

硅基视角：正则化——机器学习如何"推导出"量子化¶

紫外灾变在机器学习的语言中有一个精确的对应物：过拟合发散(overfitting divergence)。经典理论对黑体辐射的处理方式是：将腔内电磁场分解为无穷多个频率模式，然后根据能量均分定理给每个模式分配完全相同的平均能量 kBTk_BTkB​T。这等价于在一个线性回归模型中给每一个特征(feature)赋予相同的权重，不管这个特征的"代价"有多高。当特征数量有限时，这种做法或许还能接受；但当特征空间趋于无穷(在黑体问题中，高频模式的数量按 ν2\nu^2ν2 增长，没有上限)，总能量就不可避免地发散了。这和一个过参数化(overparameterized)的神经网络在没有任何约束的情况下记住训练集的每一个噪声点，导致泛化能力崩溃，本质上是同一个数学困境。

机器学习对付过拟合的标准武器是正则化(regularization)。L1 正则化(LASSO)在损失函数中加入权重绝对值之和 λ∑∣wi∣\lambda \sum |w_i|λ∑∣wi​∣ 作为惩罚项，其效果是迫使大量权重恰好变为零，产生稀疏解(sparse solution)——大部分特征被彻底"关闭"。L2 正则化(Ridge)加入权重平方和 λ∑wi2\lambda \sum w_i^2λ∑wi2​，效果是让所有权重平滑地向零收缩，高代价特征受到更强的抑制。两种方法的核心思想是相通的：不应该给所有特征平等对待，"昂贵"的特征应当被惩罚，只有那些对模型预测真正重要的特征才值得分配资源。

普朗克的能量量子化，从数学结构上看，恰好是一种频率自适应的正则化。量子化引入了一个与频率成正比的"激活成本"：要激发频率为 ν\nuν 的模式，必须至少支付 hνh\nuhν 的能量。当 hν≪kBTh\nu \ll k_BThν≪kB​T 时，这个成本微不足道，模式的行为与经典预言无异——就像正则化强度为零时权重保持原值。但当 hν≫kBTh\nu \gg k_BThν≫kB​T 时，热运动提供的能量远不足以支付这个最低成本，该模式被指数性地抑制——就像 L1 正则化将那些"代价超过收益"的特征权重直接压到零。量子平均能量 ⟨E⟩=hν/(ehν/kBT−1)\langle E \rangle = h\nu/(e^{h\nu/k_BT}-1)⟨E⟩=hν/(ehν/kB​T−1) 与经典值 kBTk_BTkB​T 之比是 (hν/kBT)/(ehν/kBT−1)(h\nu/k_BT)/(e^{h\nu/k_BT}-1)(hν/kB​T)/(ehν/kB​T−1)，这是一个从 1 平滑衰减到 0 的函数，形状与 L1 正则化产生的软阈值函数(soft-thresholding function)惊人地相似。在下面的代码中，我们将直观地看到这种对应关系。

更深一层地看，正则化与量子化的类比不仅仅是形式上的相似，而是触及了一个更根本的数学原理：对无穷维自由度的控制。在泛函分析中，一个定义在无穷维空间上的线性泛函如果不加任何约束，极容易发散。经典的能量均分定理正是这样一个不加约束的线性泛函——它给每个模式等量的能量，而模式数量趋于无穷。正则化(无论是 L1、L2 还是量子化)的本质是引入一个与"模式复杂度"成正比的惩罚，使得高复杂度模式的贡献被充分压制，从而保证总和收敛。在机器学习中，这个复杂度度量通常是权重的范数；在物理学中，它是频率 ν\nuν 乘以普朗克常数 hhh。从这个角度来看，普朗克常数 hhh 扮演的角色就是自然界的正则化超参数(regularization hyperparameter)——它设定了能量分配的最小粒度，决定了哪些模式能被激发、哪些模式被冻结，就像学习率和权重衰减系数共同决定了神经网络训练的收敛行为。如果有一天某个先进的 AI 被要求从实验数据出发"发现"物理定律，它在面对黑体辐射数据时，几乎必然会引入某种形式的正则化来避免紫外发散，而这个正则化的数学形式将不可避免地导向离散化——也就是说，AI 会独立地"重新发现"量子化。

这并非纯粹的臆测。近年来兴起的符号回归(symbolic regression)技术，如 PySR 库，正是让 AI 从数据中搜索解析公式的工具。与神经网络不同，符号回归不是拟合一个黑箱函数，而是在由基本运算符(加、减、乘、除、指数、对数等)构成的解析表达式空间中搜索，寻找能以最少的数学复杂度描述数据的公式。其核心算法基于遗传编程(genetic programming)：维护一个"公式种群"，通过变异、交叉和选择来演化出越来越好的表达式，最终输出一条 Pareto 前沿——不同复杂度下的最佳公式。如果我们将普朗克辐射数据化为无量纲变量 x=hν/kBTx = h\nu/k_BTx=hν/kB​T 和 y=u/(8πhν3/c3)y = u/(8\pi h\nu^3/c^3)y=u/(8πhν3/c3)，符号回归只需发现一个单变量函数 y=f(x)y = f(x)y=f(x)，其搜索空间大幅缩小。实际测试表明，PySR 可以从纯数据出发成功发现 y=1/(ex−1)y = 1/(e^x - 1)y=1/(ex−1)，即普朗克分布的核心数学结构。这个结果说明，当物理学家提供了正确的无量纲化(本质上是选择了正确的"特征工程")，AI 确实能够"重新发现"物理定律的解析形式。

天文应用：多波段测光与赫茨普龙-罗素图¶

维恩位移定律给出了一个从颜色推断温度的简洁方法，但天文学家在实际工作中很少能测量到完整的恒星光谱。获取一条完整光谱需要将光分散到数百个波长通道，每个通道接收到的光子数大幅减少，对暗弱天体几乎不可行。天文学家的替代方案是测光(photometry)：使用几个标准化的宽波段滤光片拍摄图像，测量恒星在每个波段的亮度。Johnson 和 Morgan 在 1953 年建立了 UBV 系统，后来扩展为 UBVRI 五波段系统，覆盖从紫外(U, 365 nm)到近红外(I, 798 nm)的主要波段。测量结果以星等(magnitude)表示，星等越小天体越亮，定义为 m=−2.5log⁡10(F/F0)m = -2.5\log_{10}(F/F_0)m=−2.5log10​(F/F0​)，其中 FFF 是观测流量，F0F_0F0​ 是零点流量(以织女星 Vega 为基准)。

两个波段星等之差称为色指数(color index)，最常用的是 B−VB-VB−V(蓝波段减可见光波段)。色指数有一个极其重要的性质：它不依赖恒星的距离和大小。无论恒星多远多小，B−VB-VB−V 只反映其表面温度。这是因为星等差消去了流量中共同的几何因子 (R⋆/d)2(R_\star/d)^2(R⋆​/d)2。蓝色高温恒星(如参宿七，T≈12000T \approx 12000T≈12000 K)的 B−VB-VB−V 为负值，红色低温恒星(如参宿四，T≈3500T \approx 3500T≈3500 K)的 B−VB-VB−V 为正值。对 5 个波段可以构造 4 个独立的色指数(U−BU-BU−B, B−VB-VB−V, V−RV-RV−R, R−IR-IR−I)，通过 χ2\chi^2χ2 拟合可以精确确定恒星的有效温度。

赫茨普龙-罗素图(HR 图)是天文学中最重要的诊断工具之一。丹麦天文学家赫茨普龙(1911 年)和美国天文学家罗素(1913 年)独立发现，如果将恒星的光度(或绝对星等 MVM_VMV​)对表面温度作图，恒星并非随机分布，而是聚集在几条清晰的带上。绝大多数恒星位于从左上(高温高光度)到右下(低温低光度)的主序带(main sequence)上，这条带反映了恒星在氢核聚变阶段的质量-光度关系。脱离主序的恒星处于演化的不同阶段：红巨星位于主序右上方(低温但高光度，意味着巨大的半径)，白矮星位于主序左下方(高温但低光度，意味着极小的半径)。HR 图不仅是恒星分类的基础，更是理解恒星演化的路线图。

宇宙热历史：从可见光到微波的冷却之旅¶

我们今天观测到的 CMB 处于微波波段(峰值波长约 1.1 mm)，但它并非一开始就是微波。在宇宙的膨胀过程中，黑体辐射的温度随宇宙尺度因子 aaa 的增大而降低。具体地，CMB 温度与红移 zzz 的关系为

z≈1100z \approx 1100z≈1100 这个时刻具有特殊的物理意义：当宇宙温度降至约 3000 K 时，自由电子与质子复合形成中性氢原子(e−+p→H+γe^- + p \to \text{H} + \gammae−+p→H+γ)，光子不再与物质频繁散射，宇宙从”不透明”变为”透明”。这一事件称为光子退耦(photon decoupling)，对应的宇宙表面称为最后散射面(last scattering surface)。退耦之后的光子便在膨胀的宇宙中自由传播，从可见光逐渐红移到红外、再到今天的微波波段。我们今天观测 CMB，实际上是在”看”138 亿年前最后散射面上的温度分布——CMB 是人类能够直接”拍照”的最古老的光。

从 AI Workshop 的视角来看，从 COBE/FIRAS 数据中提取宇宙温度只需要最简单的最小二乘拟合。但如果我们想回答更深层的问题——“数据是否需要超越标准黑体的新物理(如 μ\muμ 型谱畸变)？”——就需要更强大的统计推断工具。马尔可夫链蒙特卡洛(MCMC)方法，特别是 Metropolis-Hastings 算法，是现代天文学和宇宙学中最核心的参数估计和模型选择工具。MCMC 的基本思想是：构造一条在参数空间中随机游走的马尔可夫链，使其平衡分布恰好是我们想要采样的后验分布 p(θ∣data)p(\theta|\text{data})p(θ∣data)。通过分析链的统计性质(均值、方差、相关性)，我们可以得到参数的最佳估计及其不确定度，还可以通过贝叶斯模型选择(如热力学积分)来定量比较不同物理模型的优劣。

研究前沿（2024--2025）：黑体辐射正在从”普适定律”走向”可编程辐射”¶

术语速览（第一次读可先看）：

  • 近场：距离小到接近或小于热辐射主波长时的传热区域，行为会明显偏离远场直觉。

  • μ\muμ 畸变：早期宇宙能量注入留下的“化学势型”谱偏离。

  • yyy 畸变：光子与高温电子散射导致的“康普顿化”谱偏离。

最近两年的进展可以浓缩成四句话：

  1. 近场增强：把两个结构放到极近距离，热辐射通量可显著超过远场黑体极限，实验上已见到约 20 倍增强 Luo et al. (2024)。
    直观理解：热辐射不再只是“自然泄热”，而是可设计的能量通道。

  2. 偏振与手性：扭转纳米碳丝可以直接发出高亮度圆偏振热辐射 Lu et al. (2024)，并引出了“结构化黑体光子发射”这一方向 Ma & Lu (2025)。
    直观理解：热辐射不仅有“强弱和颜色”，还可以有“偏振态和角动量”。

  3. 工程应用：双窗口选择性发射器在白天辐射制冷上表现突出 Wu et al. (2024)。
    直观理解：黑体辐射理论正在进入建筑节能和热管理的真实系统。

  4. 宇宙学探针：高精度 CMB 光谱已用于约束暗光子等新物理模型 Arsenadze et al. (2025)。
    直观理解：黑体谱精密测量已经是基础物理的“测量工具”，不只是教学案例。

开放问题（截至 2026 年）¶

下面这 5 个问题，代表了“理论很成熟，但技术还在追赶”的现状：

  1. 极近场统一模型
    亚 10 nm 时，辐射传热会和隧穿、非局域效应、接触导热混在一起；目前缺少一个被广泛认可的统一描述。

  2. 超普朗克增强的工程可复现性
    理想实验里增强很高，但一到真实器件就会被间隙稳定性、温漂、污染层和制备误差拖累。

  3. 多自由度调控的硬权衡
    频谱选择性、方向性、偏振纯度、总功率往往不能同时拉满，设计时必须做取舍。

  4. 从样机到规模化应用
    辐射制冷材料在长期户外耐久性、封装成本、系统集成上仍需大量工程验证。

  5. CMB 光谱精度继续提升
    要直接测到更弱的 μ/y\mu/yμ/y 信号，需要同时突破绝对定标、前景分离和系统误差控制。
