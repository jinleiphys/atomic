2.3 光谱数据与经验公式¶

破译原子的状态码¶

将氢气放电管发出的光通过棱镜，你不会看到彩虹般的连续光谱，而是几条分立的、锐利的亮线，散落在特定的波长位置上。这个事实在 19 世纪初就已为人所知，但它的深层含义远非显而易见。太阳光或白炽灯光通过棱镜后展开为连续的色带，从红到紫平滑过渡，每个波长都有光存在。然而，当你把一根充满稀薄氢气的玻璃管接上高压电源，让电流激发气体发光，再让这束光通过棱镜时，暗色的背景上只出现几条孤零零的彩色细线。这些线条的位置极其精确、极其稳定，无论你在柏林还是在巴黎做实验，无论你用哪一批氢气，得到的谱线波长都完全一致。

每种元素都有自己独特的光谱线组合，这就是原子的"指纹"。1860 年代，基尔霍夫(Kirchhoff)和本生(Bunsen)利用光谱分析法发现了铯和铷两种新元素，开创了光谱学的黄金时代。此后数十年间，光谱学家们用越来越精密的仪器测量了大量元素的光谱波长，积累了庞大的数据表格。埃格斯特朗(Ångström)在 1868 年发表了太阳光谱中的数千条谱线的精确波长，精度达到小数点后六位。但面对这些浩如烟海的数据，物理学家们陷入了困惑：这些数字看起来毫无规律，只是一串串"随机"的波长值。光谱学拥有大量精确的实验数据，却没有任何理论框架来解释它们。正如一位历史学家所形容的那样，光谱学在当时是"天文学般精确、植物学般描述性"的学科——能精确测量，但无法理解。

这种局面在 1885 年发生了戏剧性的转变。瑞士巴塞尔的一位数学教师约翰·巴尔末(Johann Jakob Balmer, 1825–1898)，在 60 岁那年破译了氢原子光谱的密码。巴尔末并不是物理学家，他的日常工作是在巴塞尔的一所女子学校教授数学，业余时间研究数论和几何。他对数字之间的和谐关系有一种近乎痴迷的直觉，曾花大量时间研究建筑比例和数字规律。据说是他的同事、巴塞尔大学物理学教授哈根巴赫(Eduard Hagenbach)向他提到了氢原子光谱的数据，并问他能否从中找到什么数学规律。巴尔末接受了这个挑战。

摆在巴尔末面前的数据是氢原子在可见光区的四条主要谱线：HαH_\alphaHα​ 波长 656.3 nm，是一条鲜艳的红色线；HβH_\betaHβ​ 波长 486.1 nm，呈蓝绿色；HγH_\gammaHγ​ 波长 434.0 nm，是蓝紫色的；HδH_\deltaHδ​ 波长 410.2 nm，接近紫色的边缘。这四个数字——656.3、486.1、434.0、410.2——它们之间有什么关系？

巴尔末的方法完全是数字游戏式的。他反复摆弄这些数字，计算它们的比值、差值、平方、倒数，寻找隐藏的模式。经过大量尝试，他发现如果取这些波长的比值，可以写成简单分数：656.3/364.56=9/5656.3 / 364.56 = 9/5656.3/364.56=9/5，486.1/364.56=4/3486.1 / 364.56 = 4/3486.1/364.56=4/3，434.0/364.56=25/21434.0 / 364.56 = 25/21434.0/364.56=25/21，410.2/364.56=9/8410.2 / 364.56 = 9/8410.2/364.56=9/8。而这些分数的分子分母可以进一步分解：9/5=32/(32−4)9/5 = 3^2/(3^2 - 4)9/5=32/(32−4)，4/3=42/(42−4)4/3 = 4^2/(4^2 - 4)4/3=42/(42−4)，25/21=52/(52−4)25/21 = 5^2/(5^2 - 4)25/21=52/(52−4)，9/8=62/(62−4)9/8 = 6^2/(6^2 - 4)9/8=62/(62−4)。规律赫然浮现。巴尔末写下了他的公式：

λ=Bn2n2−4,n=3,4,5,6,…\lambda = B \frac{n^2}{n^2 - 4}, \quad n = 3, 4, 5, 6, \ldotsλ=Bn2−4n2​,n=3,4,5,6,…
(1)

其中 B=364.56B = 364.56B=364.56 nm。这个公式用一个常数和一个整数就能精确地再现所有四条已知谱线的波长，而且巴尔末大胆地将它用于预测：当 n=7n = 7n=7 时，公式给出波长 397.0 nm。后来的测量完全证实了这一预测。巴尔末在他 1885 年的论文《关于氢光谱线的一个注记》(“Notiz über die Spectrallinien des Wasserstoffs”)中，甚至预言了当 n→∞n \to \inftyn→∞ 时谱线应当趋向一个极限波长 B=364.56B = 364.56B=364.56 nm，也就是巴尔末系的系限(series limit)。这一切都被后来的实验逐一证实。

巴尔末公式在物理学界引起了巨大反响。一方面，它的成功是毋庸置疑的——一个如此简洁的表达式竟能以极高精度再现实验数据，这本身就令人惊叹。另一方面，物理学家们深感不安，因为没有人知道这个公式为什么是对的。公式中的数字 4 从何而来？整数 nnn 代表什么？常数 BBB 的物理含义是什么？巴尔末自己也无法回答这些问题。他的公式是纯粹经验性的——从数据中"凑"出来的，没有任何物理图像作为支撑。但正是这种"没有理论解释的精确规律"最能折磨物理学家的心智。它像一封加密的信件：你能读出每个字母，但不懂它在说什么。每个人都相信，这个公式背后一定隐藏着某种深刻的物理机制，但在当时，还没有人能够揭示它。

巴尔末公式的出现激发了一场对光谱规律的系统搜索。1888 年，瑞典物理学家里德伯(Johannes Robert Rydberg, 1854–1919)将巴尔末公式推广为一个远为一般的形式。里德伯的推广并非凭空猜测，而是建立在三条清晰的线索之上。第一条线索来自巴尔末公式本身的改写。将巴尔末公式变换为波数形式：1/λ=(4/B)(1/4−1/n2)1/\lambda = (4/B)(1/4 - 1/n^2)1/λ=(4/B)(1/4−1/n2)，里德伯敏锐地注意到分母中的 4 其实就是 22，于是公式变成了 1/λ=RH(1/22−1/n2)1/\lambda = R_H(1/2^2 - 1/n^2)1/λ=RH​(1/22−1/n2)。这里的 2 看起来不像一个"基本"的数字，更像是某个更一般参数的特殊取值。第二条线索来自碱金属光谱的比较研究。里德伯系统地研究了锂、钠、钾等多种碱金属元素的光谱，发现它们虽然比氢复杂得多，但都呈现出一个共同的数学结构：每条谱线的波数都可以表示为两个"项"(term)的差，ν~=T(n1)−T(n2)\tilde{\nu} = T(n_1) - T(n_2)ν~=T(n1​)−T(n2​)。这种"两项之差"的结构在不同元素中反复出现，强烈暗示它不是巧合，而是原子结构的某种普遍特征。对氢原子这个最简单的情形，项函数取最简洁的形式 T(n)=RH/n2T(n) = R_H/n^2T(n)=RH​/n2，巴尔末系恰好对应 T(2)−T(n)T(2) - T(n)T(2)−T(n)。那么一个自然的问题就浮现了：T(1)−T(n)T(1) - T(n)T(1)−T(n)、T(3)−T(n)T(3) - T(n)T(3)−T(n) 是否也对应着尚未被发现的谱线系？第三条线索来自里兹(Walther Ritz)在 1908 年提出的组合原理：如果两条已知谱线的波数分别是 T(a)−T(b)T(a)-T(b)T(a)−T(b) 和 T(b)−T(c)T(b)-T(c)T(b)−T(c)，那么它们的和 T(a)−T(c)T(a)-T(c)T(a)−T(c) 也应该对应一条实际存在的谱线。这个预言被实验反复验证，进一步证实了"项"结构的物理实在性。正是基于这些线索，里德伯将巴尔末公式推广为波数形式：

1λ=R∞(1n12−1n22),n2>n1\frac{1}{\lambda} = R_\infty \left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right), \quad n_2 > n_1λ1​=R∞​(n12​1​−n22​1​),n2​>n1​
(2)

其中 R∞=1.097×107 m−1R_\infty = 1.097 \times 10^7 \text{ m}^{-1}R∞​=1.097×107 m−1 是里德伯常数。当 n1=2n_1 = 2n1​=2 时，这就是巴尔末公式。但里德伯公式的威力远不止于此：n1=1n_1 = 1n1​=1 给出莱曼系(Lyman series)，这些谱线位于紫外区，直到 1906 年才被莱曼(Theodore Lyman)实验发现；n1=3n_1 = 3n1​=3 给出帕邢系(Paschen series)，位于红外区，1908 年由帕邢(Friedrich Paschen)证实；n1=4n_1 = 4n1​=4 给出布拉凯特系(Brackett series)，n1=5n_1 = 5n1​=5 给出普芬德系(Pfund series)……这些谱线系在里德伯发表公式后的数十年间逐一被实验发现，每一次发现都是对里德伯公式预言的精确验证。

里德伯公式的深刻之处在于它揭示的结构。所有氢原子光谱线的波长，无论它们落在紫外、可见光还是红外区域，都可以用一个常数 R∞R_\inftyR∞​ 和两个正整数 n1n_1n1​、n2n_2n2​ 来完全确定。一个常数统一了无穷多条谱线。这种统一性强烈暗示，原子内部存在某种由整数标记的离散状态，而光谱线的发射对应着原子从一个状态到另一个状态的跃迁。整数 nnn 后来被称为量子数(quantum number)，而里德伯公式成了量子力学诞生之前最重要的线索之一。从 1885 年巴尔末发现他的公式，到 1913 年玻尔(Niels Bohr)提出他的原子模型从理论上推导出里德伯常数的表达式，中间整整 28 年。在这漫长的等待期间，里德伯公式一直是一个没有理论解释却无比精确的经验公式，像一座灯塔，指引着物理学家们寻找正确的原子理论。

硅基视角：符号回归¶

巴尔末在 1885 年所做的事情，用现代数据科学的语言来说，就是符号回归(Symbolic Regression)：给定一组数据点，搜索能够拟合数据的解析表达式。与常见的数值回归(如线性回归、多项式回归)不同，符号回归的目标不仅仅是拟合数据，而是找到数据背后的数学结构——一个具有物理意义的简洁公式。这正是巴尔末所做的事情，只不过他用的"算法"是人类大脑的直觉和耐心。

从信息论的角度来看，里德伯公式所实现的是一种惊人的数据压缩。氢原子可以发出无穷多条光谱线，每条谱线的波长需要若干位有效数字来表示。如果我们逐条列出这些波长，需要一张无穷长的数据表。但里德伯公式用一个常数 R∞R_\inftyR∞​ 和两个整数 (n1n_1n1​, n2n_2n2​) 就能精确重建任意一条谱线的波长。这就像把一个无穷大的数据库压缩成了一行代码。这种压缩不是有损的近似压缩(lossy compression)——像 JPEG 压缩图片那样牺牲一些细节——而是无损压缩(lossless compression)，原始数据可以被完美复原。在计算机科学中，我们知道只有当数据中存在内在规律时，无损压缩才有可能。因此，里德伯公式的存在本身就证明了光谱数据中蕴含着深层的物理规律。

更深一层地思考，里德伯公式揭示了原子光谱的一种组合结构。每条光谱线的波数(频率)并不是一个独立的值，而是两个"项"(term)的差：ν~=T(n1)−T(n2)\tilde{\nu} = T(n_1) - T(n_2)ν~=T(n1​)−T(n2​)，其中 T(n)=R∞/n2T(n) = R_\infty / n^2T(n)=R∞​/n2。这就是所谓的里兹组合原理(Ritz combination principle)。这意味着，与其存储所有光谱线的波长(一个二维数组)，你只需要存储一个一维的"项值"序列 T(1),T(2),T(3),…T(1), T(2), T(3), \ldotsT(1),T(2),T(3),…，然后通过两两作差就能重建所有光谱线。在计算机科学中，这类似于用一个长度为 NNN 的数组来表示一个 N×NN \times NN×N 的矩阵——当矩阵的每个元素都等于某一行值减去某一列值时，存储复杂度从 O(N2)O(N^2)O(N2) 降至 O(N)O(N)O(N)。原子光谱恰好具有这种结构，而里德伯公式和里兹组合原理正是对这种结构的精确表述。

从符号回归的现代实践来看，巴尔末面对的问题规模其实非常小：只有四个数据点(四条可见光谱线)，搜索空间是由基本算术运算和整数幂构成的简单表达式。今天的符号回归算法(如基于遗传编程的 PySR 或基于变分方法的 AI Feynman)可以在几秒钟内从数百万个候选公式中找到最佳拟合。然而，巴尔末在没有计算机的情况下完成了这项工作，靠的是对数字比例的敏锐直觉和不厌其烦的手工计算。从这个意义上说，巴尔末是人类历史上最早的"符号回归者"之一。他的成功提醒我们，科学发现的本质——从嘈杂的数据中提取简洁的规律——与数据压缩和模式识别有着深刻的共通之处。

下面的代码示例展示了如何用最简单的线性回归方法，从氢原子巴尔末系的实验波长数据中"重新发现"里德伯常数。

import numpy as np
from scipy import stats

# 氢原子巴尔末系 (n1=2) 的实验波长数据 (nm)
n2 = np.array([3, 4, 5, 6, 7])
lambda_exp = np.array([656.3, 486.1, 434.0, 410.2, 397.0])  # nm

# 里德伯公式: 1/λ = R * (1/n1² - 1/n2²)
# 令 x = (1/4 - 1/n2²), y = 1/λ
# 则 y = R * x (过原点的线性关系)

x = 1/4 - 1/n2**2
y = 1 / (lambda_exp * 1e-9)  # 转换为 m⁻¹

# 线性回归 (强制过原点)
slope, _, _, _, _ = stats.linregress(x, y)

print(f"拟合得到的里德伯常数: R = {slope:.4e} m⁻¹")
print(f"标准值:              R = 1.0974e+07 m⁻¹")
print(f"相对误差: {abs(slope - 1.0974e7)/1.0974e7 * 100:.2f}%")

  2. 巴尔末在1885年发现了他的公式，但玻尔模型直到1913年才出现。在这28年间，物理学家们如何看待巴尔末公式？一个"没有理论解释"的经验公式有价值吗？
