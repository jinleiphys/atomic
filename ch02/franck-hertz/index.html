2.5 弗兰克-赫兹实验¶

用电子敲门¶

光谱学为原子能级的存在提供了间接但令人信服的证据：原子发射和吸收特定频率的光，这些离散的谱线可以通过玻尔模型中定态之间的跃迁来解释。然而，从严格的实验逻辑来看，光谱学证据毕竟是间接的。我们观察到的是光子，而非原子本身的能量状态。有没有一种方法，可以绕过光谱，直接用一种"探针"去试探原子能接受多大的能量，从而在最基础的层面上验证能级的离散性？1914年，德国物理学家詹姆斯·弗兰克(James Franck)和古斯塔夫·赫兹(Gustav Hertz)正是用这样的思路，设计了一个简洁而深刻的实验，为原子物理学提供了最直接的实验证据。

弗兰克1882年生于汉堡，在海德堡大学获得博士学位后前往柏林大学工作，专注于气体中电子碰撞过程的研究。赫兹是伟大的电磁学先驱海因里希·赫兹(Heinrich Hertz)的侄子，1887年生于汉堡，同样在柏林大学取得了出色的学术成绩。两人于1913年在柏林大学物理研究所相遇，开始了一段改变物理学进程的合作。值得注意的是，弗兰克和赫兹最初并非为了验证玻尔模型而设计这个实验。事实上，他们在1914年初发表论文时，对玻尔1913年发表的原子模型并不十分了解，也没有在论文中引用玻尔的工作。他们最初的兴趣是研究电子与气体原子碰撞时的能量转移过程，特别是想测量汞的电离电位(ionization potential)。他们以为自己测到的4.9 eV是汞的电离能，而非第一激发能。这个"误解"反而使得他们的实验结果更加引人注目：实验的客观发现超越了实验者最初的主观预期，这正是伟大实验的标志。

弗兰克-赫兹实验的装置构思精巧却并不复杂。在一个密封的玻璃管中充入低压的汞蒸气，管的一端是一根加热的钨丝阴极，通过热发射源源不断地释放出电子。阴极附近设有一个栅网状的加速极(阳极栅网)，在阴极和栅网之间施加一个可调节的加速电压 VVV，使电子从阴极出发后被加速获得动能。加速后的电子穿过栅网，进入充满汞蒸气的空间，在这里与汞原子发生碰撞。在栅网的另一侧，紧邻着一个收集极(collector)，但关键的一步在于：在栅网与收集极之间施加了一个微小的反向电压(约0.5 V)，形成一个减速电场。只有那些穿过栅网后仍然保留了足够动能的电子，才能克服这个反向电势差到达收集极，被收集极的灵敏电流计记录下来。那些在碰撞中失去了大量动能的电子则无法通过这道"最后的关卡"，会被反向电场推回。实验的核心测量就是：缓缓增大加速电压 VVV，同时记录收集极电流 III 随 VVV 的变化曲线。

如果原子的能量吸收是连续的，正如经典物理学所预期的那样，那么随着加速电压的增大，电子获得越来越大的动能，与汞原子碰撞时损失的能量也应连续增加，收集极电流应该大致单调地上升。然而弗兰克和赫兹观察到的实验结果完全出乎意料。当加速电压从零逐渐升高时，在 V<4.9V < 4.9V<4.9 V的范围内，电流确实随电压的增大而平稳上升。在这个阶段，电子的动能还不够大，与汞原子碰撞时只能发生弹性碰撞。由于电子质量远小于汞原子(质量比约为1:370000)，弹性碰撞中电子几乎不损失动能，就像乒乓球弹到保龄球上一样，基本上被原样弹回。因此这些电子穿过汞蒸气后仍保持着足够的动能，可以轻松越过反向电压的势垒到达收集极。

但当加速电压升高到大约4.9 V附近时，电流出现了戏剧性的突然下降。这意味着大量电子在穿过汞蒸气时突然失去了几乎全部的动能，以至于无法再克服仅仅0.5 V的反向电压。弗兰克和赫兹意识到，这只能有一种解释：当电子的动能恰好达到4.9 eV时，它与汞原子之间发生了一种全新类型的碰撞，即非弹性碰撞(inelastic collision)。在这种碰撞中，电子将4.9 eV的能量整体地、一次性地转交给汞原子，激发汞原子从基态跃迁到某个激发态，而电子自身的动能则骤降至接近于零，自然无法到达收集极。

当加速电压继续升高超过4.9 V后，电流又开始恢复上升。这是因为电子现在获得了超过4.9 eV的动能，在与汞原子发生非弹性碰撞、交出4.9 eV之后，仍保留了一些剩余动能，足以通过反向电压。但当电压升至大约9.8 V时，电流再次下降。原因很清楚：此时电子的动能足以在路径上经历两次非弹性碰撞，每次各交出4.9 eV，两次碰撞之后又变得动能不足。这个模式持续重复下去，在14.7 V、19.6 V、24.5 V处都出现了电流的下降。电流-电压曲线最终呈现出以4.9 V为周期的锯齿形振荡，这是弗兰克-赫兹实验最具标志性的实验特征。

这个结果的物理意义是深远的。弗兰克-赫兹实验以一种与光谱学完全不同的方式，直接证明了汞原子只能吸收特定大小的能量(4.9 eV)，这对应于汞原子从基态到第一激发态(6\,^1S_0 \to 6\,^3P_1)的跃迁能量。原子对能量的吸收不是连续的、可以取任意值的，而是"全有或全无"的：要么完整地接受4.9 eV并跃迁，要么什么也不接受而保持弹性碰撞。这正是玻尔定态假设的直接验证，原子确实拥有离散的能级结构。更令人信服的是，弗兰克和赫兹还观察到，当电子的能量超过4.9 eV并激发了汞原子之后，汞蒸气会发出波长为253.7 nm的紫外辐射，其光子能量恰好等于 hν=4.9h\nu = 4.9hν=4.9 eV。这完美地闭合了证据链：电子把4.9 eV的能量交给汞原子，汞原子从激发态退回基态时以光子的形式释放了这些能量，而光子的能量与电子转移的能量精确吻合。

弗兰克-赫兹实验的论文发表后，玻尔立刻认识到这个实验为他的原子理论提供了最强有力的支持。然而历史的讽刺在于，弗兰克和赫兹本人在最初的论文中却并未将自己的结果与玻尔模型联系起来。他们将4.9 eV解读为汞的电离电位而非第一激发能。直到后来的实验和理论交流让他们认识到了正确的物理解释。这段科学史清楚地说明了一个道理：实验事实可以先于理论理解而存在，伟大的实验有时会揭示出连实验者自己都未曾预料到的真理。1925年，弗兰克和赫兹因为这个实验共同获得了诺贝尔物理学奖。诺贝尔委员会的授奖词明确指出，他们的贡献在于"发现了支配电子与原子碰撞的定律"。这个实验至今仍是大学物理实验课程中的经典项目，每一代物理学学生都在这个实验中亲眼见证原子能级的离散性。

硅基视角：阈值测试¶

在计算机工程领域，当你面对一个功能未知的硬件设备时，最基本的测试策略之一就是阈值测试(threshold testing)：你向设备的输入端口逐步增大输入信号的幅度，同时监视输出端口的响应，从而判断设备内部的信号处理机制。如果输出随输入线性变化，说明内部是模拟电路，信号的传输和放大是连续的。但如果输出在某些特定的输入值处发生突变，而在其他值处几乎没有响应，那就说明内部存在数字逻辑，系统的状态空间是离散的、有限的，只有当输入达到或超过某个阈值时，系统才会从一个状态翻转到另一个状态。

从这个角度重新审视弗兰克-赫兹实验，我们会发现它的本质就是一次对原子的阈值测试。实验者将电子当作"测试信号"，将其能量从零逐步增大，注入汞原子这个"待测设备"，然后观察"输出"(收集极电流)的变化。实验结果清楚地表明，原子的能量输入端口是数字的而非模拟的。当输入能量低于4.9 eV时，原子完全不响应，就像数字电路在输入低于逻辑阈值时保持不变一样，电子与原子之间只发生弹性碰撞，能量不被原子吸收。当输入能量恰好达到4.9 eV时，原子突然响应，吸收全部4.9 eV的能量并发生状态跳变，从基态跃迁到激发态，这对应于数字电路中的状态翻转。当输入能量介于4.9 eV和9.8 eV之间时，原子仍然只执行一次跳变，吸收4.9 eV，多余的能量留给了电子作为剩余动能。当输入能量达到9.8 eV时，电子可以沿路径触发两次跳变，每次4.9 eV。以此类推。

这种行为模式与数字电路中的施密特触发器(Schmitt trigger)在功能上是同构的。施密特触发器是一种带有迟滞特性的比较器，只有当输入电压上升到超过上阈值 V+V_+V+​ 时，输出才从低电平翻转为高电平；输入必须下降到低于下阈值 V−V_-V−​ 时，输出才翻回低电平。在弗兰克-赫兹实验中，4.9 eV就扮演着上阈值的角色：电子能量低于此值时，原子保持基态不变("输出"为低)；超过此值时，原子发生状态翻转("输出"为高)。当然，原子与施密特触发器之间也存在区别。施密特触发器的阈值由外部电阻网络设定，是可调的，而原子的能级间距则由量子力学决定，是自然常数的函数，不可调节。但两者共同传达的核心信息是一致的：系统的状态空间是离散的，状态之间的跃迁是突变的而非渐变的。

更深入地思考这个类比，弗兰克-赫兹实验实际上揭示了一种"量化的输入协议"。在现代数字通信中，模数转换器(ADC)将连续的模拟信号转化为离散的数字信号，信号的幅度被量化为有限个离散的等级。原子在某种意义上就是自然界最原始的"模数转换器"：它接收的能量是连续可变的(电子可以携带任意大小的动能)，但它实际能够接受和存储的能量只有有限的几个离散值(对应于各个激发态的能量)。这种"量化输入"的本质正是量子力学的核心特征，也是"量子"(quantum)这个词最原始的含义——能量的基本单元。

import numpy as np
import matplotlib.pyplot as plt

def franck_hertz_current(V, V_threshold=4.9, V_retard=0.5):
    """
    简化的弗兰克-赫兹电流模型
    V: 加速电压
    V_threshold: 激发电位 (汞的第一激发态 = 4.9 V)
    V_retard: 反向阻止电压
    """
    I = np.zeros_like(V)
    for i, v in enumerate(V):
        if v <= V_retard:
            I[i] = 0
            continue

        # 电子在路径上可能经历多次非弹性碰撞
        n_collisions = int(v / V_threshold)  # 碰撞次数
        E_residual = v - n_collisions * V_threshold  # 剩余动能 (eV)

        # 只有剩余动能 > 反向电压时才能到达收集极
        if E_residual > V_retard:
            I[i] = (E_residual - V_retard) * (1 + 0.1 * v)
        else:
            I[i] = 0.01 * v  # 微小的漏电流

    # 加一些噪声使其更真实
    I += np.random.normal(0, 0.02 * I.max(), len(I))
    I = np.maximum(I, 0)
    return I

V = np.linspace(0, 25, 1000)
I = franck_hertz_current(V)

plt.figure(figsize=(10, 5))
plt.plot(V, I, 'b-', linewidth=1)
plt.xlabel('加速电压 V (V)')
plt.ylabel('收集极电流 I (a.u.)')
plt.title('弗兰克-赫兹实验模拟 (汞)')

# 标注阈值
for n in range(1, 6):
    plt.axvline(x=n*4.9, color='red', linestyle='--', alpha=0.4)
    plt.text(n*4.9, plt.ylim()[1]*0.95, f'{n*4.9:.1f}V',
             ha='center', fontsize=8, color='red')

plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('franck_hertz.png', dpi=150)
plt.show()

思考题¶

  1. 弗兰克-赫兹实验中，为什么电流曲线呈现周期性振荡而不是阶梯状？电子在失去能量后会发生什么？

  2. 弗兰克-赫兹实验能否观测到汞原子的更高激发态？如果能，实验曲线会呈现什么特征？

  3. 弗兰克和赫兹在1914年做这个实验时，他们的初衷是验证什么？他们当时知道玻尔模型吗？科学发现中"意外"和"预期"各扮演什么角色？

  4. 弗兰克-赫兹实验常被称为"直接证明"了原子能级的存在。什么叫"直接证明"？与光谱学证据相比，这个实验有什么独特的说服力？
