2.2 光电效应¶

从火花到量子：光的粒子性回归¶

1887 年，海因里希·赫兹(Heinrich Hertz)在验证麦克斯韦电磁波理论的实验中，注意到了一个意想不到的副产品：当紫外光照射到放电间隙的电极上时，放电变得更容易发生。赫兹忠实地记录了这一现象，却没有深究其原因。次年，他的学生哈尔瓦克斯(Wilhelm Hallwachs)用更系统的方式研究了这个效应：将一块锌板连接到验电器上，用紫外光照射锌板，验电器的指针发生偏转，表明锌板失去了负电荷。这就是光电效应(photoelectric effect)的最早发现。光照射金属表面，会使金属释放出带负电的粒子，这些粒子后来被汤姆孙(J.J. Thomson)在 1897 年确认为电子。

光电效应的实验装置并不复杂。将两块金属电极封装在一个抽成真空的玻璃管中，其中一块作为阴极(cathode)，另一块作为阳极(anode)。用单色光照射阴极表面，如果光的频率足够高，阴极就会发射电子，这些光电子在电场作用下飞向阳极，形成光电流。在阴极和阳极之间施加可调节的电压：当阳极为正电位时，电场加速电子，光电流增大并趋于饱和；当阳极为负电位(即施加反向电压)时，电场减速电子，光电流减小。逐渐增大反向电压，直到光电流恰好降为零，此时的电压称为遏止电压(stopping voltage) VsV_sVs​。遏止电压的物理含义非常清晰：它恰好能把最快的光电子减速到零，因此光电子的最大动能为 Kmax⁡=eVsK_{\max} = eV_sKmax​=eVs​，其中 eee 是电子电荷。通过测量不同光频率和不同光强度下的遏止电压，物理学家们得到了一系列令人困惑的实验结果。

经典电磁理论将光视为连续的电磁波。按照这一图像，光波的能量均匀地分布在波前上，金属表面的电子从入射光波中持续吸收能量，当积累的能量超过将电子束缚在金属中的势能时，电子就会逸出。这个图像直观而合理，但它在三个关键预言上与实验结果产生了尖锐的矛盾。

第一个矛盾关于响应时间。按照经典理论，光波的能量均匀地铺展在波前上。一个原子的截面大约为 10-20 m2^22，以普通光源的强度计算，单个电子要从光波中积累足够逸出的能量(通常需要几个电子伏特)，按经典估算需要数秒乃至数分钟的时间。然而实验表明，光电效应几乎是瞬时发生的，从光照射到电子逸出的延迟时间不超过 10-9 秒。这个时间尺度与经典预期相差了十个数量级以上。无论如何调整经典模型的参数，都无法解释如此短的响应时间。

第二个矛盾关于光强度与动能的关系。经典理论预言，光波的强度(即单位面积上的能量通量)越大，波的电场振幅越大，电子从中获得的能量越多，因此光电子的最大动能应当随光强度的增大而增大。然而勒纳德(Philipp Lenard)在 1902 年的精密实验表明，增大光的强度只会增加光电流(即增加逸出电子的数目)，但遏止电压 VsV_sVs​ 完全不变。也就是说，每个光电子获得的最大动能 Kmax⁡=eVsK_{\max} = eV_sKmax​=eVs​ 与光的强度无关。这一结果对经典理论构成了致命的打击：如果光的能量是连续地弥散在波前上的，更强的光波理应给电子更多的能量，但实验告诉我们并非如此。

第三个矛盾关于截止频率。实验发现，对于每种金属，都存在一个特定的截止频率(cutoff frequency) ν0\nu_0ν0​：当入射光的频率低于 ν0\nu_0ν0​ 时，无论光有多强、照射时间有多长，都不会有光电子产生。经典理论无法解释为什么存在这样一个频率阈值——在经典图像中，只要照射时间足够长，任何频率的光都应当能让电子积累到足够的能量逸出。更令人费解的是，当对不同金属测量遏止电压 VsV_sVs​ 与入射光频率 ν\nuν 的关系时，实验得到了一组平行的直线：不同金属的直线与频率轴的交点各不相同(对应不同的截止频率)，但所有直线的斜率完全相同。这个普适的斜率指向某个与金属材料无关的基本常数。

爱因斯坦的光量子假说¶

1905 年，在伯尔尼专利局工作的阿尔伯特·爱因斯坦(Albert Einstein)发表了一篇论文，标题是《关于光的产生和转化的一个启发性观点》(“Über einen die Erzeugung und Verwandlung des Lichtes betreffenden heuristischen Gesichtpunkt”)。值得强调的是，爱因斯坦的光量子假说并非凭空猜想，而是从普朗克已有的黑体辐射公式中严格推理得出的。他的论证集中在普朗克公式的高频极限——也就是维恩区(hν≫kBTh\nu \gg k_BThν≫kB​T)。回忆我们在黑体辐射一节中讨论过的：正是在这个高频区域，经典的瑞利-金斯公式彻底失败，而普朗克的量子修正起了决定性作用。爱因斯坦计算了维恩区辐射的熵随体积的变化关系，发现其数学形式与由 NNN 个独立粒子组成的理想气体的熵完全相同。理想气体的熵之所以具有那种特定的体积依赖性，是因为气体由离散的、可独立定位的粒子组成。既然高频辐射的熵表现出完全相同的数学结构，爱因斯坦大胆地推断：高频辐射在热力学上的行为就好像它是由一个个离散的能量单元组成的，每个单元的能量为 E=hνE = h\nuE=hν。

这是一个比普朗克走得更远的革命性步骤。普朗克只是假设腔壁中的振子以离散方式吸收和释放能量，但他并没有质疑光本身的连续性——他把量子化看作物质(振子)的性质，光仍然是经典的电磁波。爱因斯坦则把量子化从物质推广到了光本身，宣称光在自由空间中传播时就已经是量子化的——光不是均匀弥散的波，而是一颗颗"能量子弹"。这一推广的逻辑其实相当自然：如果普朗克公式在高频区的量子修正是物理实在的(而不只是数学技巧)，那么辐射场本身就必须具有离散结构。爱因斯坦的勇气在于，他把普朗克视为"权宜之计"的量子化当作了关于自然界的真实陈述。

爱因斯坦的光量子假说以一种优雅的方式解释了光电效应的全部实验事实。在爱因斯坦的图像中，光与电子之间的能量交换是"全有或全无"(all or nothing)的：一个光子将其全部能量 hνh\nuhν 一次性地交给一个电子，而不是像经典波那样缓慢地、连续地传递能量。如果光子的能量 hνh\nuhν 大于将电子从金属中拉出所需的最小能量(称为功函数 ϕ\phiϕ)，电子就能逸出，多余的能量转化为电子的动能。如果 hν<ϕh\nu < \phihν<ϕ，哪怕有再多的光子，每个光子的能量都不够把电子拉出来，光电效应就不会发生。爱因斯坦由此写下了光电效应方程：

Kmax⁡=hν−ϕK_{\max} = h\nu - \phiKmax​=hν−ϕ
(1)

这个方程一举解释了经典理论无法理解的三个实验事实。响应时间的问题迎刃而解：光子与电子之间的能量交换是瞬时的单次事件，不需要积累，因此响应时间可以极短。动能与光强无关的问题也得到了解释：增大光强意味着增加光子的数量，但每个光子的能量 hνh\nuhν 不变，所以单个电子获得的最大动能不变，而光电流(正比于逸出电子的数目)自然随光强增大。截止频率的存在变得理所当然：令 Kmax⁡=0K_{\max} = 0Kmax​=0，得到截止频率 ν0=ϕ/h\nu_0 = \phi/hν0​=ϕ/h。频率低于 ν0\nu_0ν0​ 的光子的能量不足以克服功函数，因此无法产生光电子，与光强和照射时间无关。不同金属的功函数 ϕ\phiϕ 不同，所以截止频率不同，但光电效应方程中 Kmax⁡K_{\max}Kmax​ 对 ν\nuν 的斜率恒为 hhh，这就是实验中观察到的那个与金属无关的普适斜率。

爱因斯坦的光量子假说在当时并未立即被物理学界接受。即使是普朗克本人，虽然承认爱因斯坦在相对论等方面的天才，也对光量子的概念持保留态度。光的波动性已经被杨氏双缝实验、衍射、偏振等大量实验无可争辩地证实了，光量子似乎是对这些铁证的否定。美国实验物理学家密立根(Robert Millikan)从 1905 年开始，花了整整十年时间进行极其精密的光电效应实验，初衷恰恰是要推翻爱因斯坦的理论。然而，密立根在 1916 年发表的实验结果却完美地证实了爱因斯坦的光电效应方程：遏止电压与频率之间确实呈精确的线性关系，斜率给出的 hhh 值与普朗克从黑体辐射数据得到的值完全一致。密立根本人在论文中写道："尽管(爱因斯坦理论)不合理到了荒谬的地步，因为它似乎与我们所知的关于光干涉的一切相矛盾……"但实验结果就是如此。1921 年，爱因斯坦凭借光电效应的理论解释获得了诺贝尔物理学奖。密立根本人后来也因为包括光电效应实验在内的精密测量工作获得了 1923 年的诺贝尔奖。

光电效应方程的应用非常直接。考虑这样一个问题：波长为 300 nm 的紫外光能否使银(功函数 ϕ=4.73\phi = 4.73ϕ=4.73 eV)发射光电子？要回答这个问题，我们先计算银的截止波长。由 ν0=ϕ/h\nu_0 = \phi/hν0​=ϕ/h，截止波长 λ0=c/ν0=hc/ϕ\lambda_0 = c/\nu_0 = hc/\phiλ0​=c/ν0​=hc/ϕ。利用常用的换算关系 hc=1240hc = 1240hc=1240 eV⋅\cdot⋅nm，得到 λ0=1240/4.73=262\lambda_0 = 1240/4.73 = 262λ0​=1240/4.73=262 nm。入射光的波长 300 nm 大于截止波长 262 nm，这意味着入射光的频率低于截止频率(因为波长与频率成反比)，每个光子的能量 hν=hc/λ=1240/300=4.13h\nu = hc/\lambda = 1240/300 = 4.13hν=hc/λ=1240/300=4.13 eV 不足以克服银的功函数 4.73 eV。因此，300 nm 的光无法使银产生光电子，无论光有多强都不行。如果换成波长 200 nm 的光，光子能量为 1240/200=6.201240/200 = 6.201240/200=6.20 eV，超过功函数，此时光电子的最大动能为 Kmax⁡=6.20−4.73=1.47K_{\max} = 6.20 - 4.73 = 1.47Kmax​=6.20−4.73=1.47 eV。

从更宏观的历史视角来看，从"数学工具"到"物理实在"的认识转变——普朗克视量子化为权宜的计算手段，爱因斯坦视之为自然界的真实结构——是量子论从含糊的直觉发展为清晰的物理理论的关键一步。

硅基视角：让 AI 从实验数据中重新发现光电方程¶

在上一节的黑体辐射中，我们看到符号回归可以从普朗克辐射数据中重新发现 1/(ex−1)1/(e^x - 1)1/(ex−1) 这个非平凡的数学结构。光电效应提供了一个更简洁但同样深刻的测试场景：如果我们把密立根精心测量的实验数据交给 AI，假装完全不知道任何物理理论，AI 能从中发现什么？

让我们从数据本身出发。密立根测量了多种金属在不同频率紫外光照射下的遏止电压 VsV_sVs​。对于每一种金属，数据看起来就是一组 (ν,Vs)(\nu, V_s)(ν,Vs​) 的散点。我们先不告诉 AI 这些数据背后的物理，只是把数据交给符号回归算法(PySR)，让它在所有可能的数学公式中搜索。结果几乎是瞬间的：PySR 很快就发现最佳公式是线性关系 Vs=aν+bV_s = a\nu + bVs​=aν+b。这并不令人惊讶——毕竟线性关系是最简单的数学结构之一，当数据确实是线性的时候，任何回归算法都能轻松找到。

真正有趣的是下一步。当我们对五种不同的金属分别运行符号回归时，每种金属都给出了线性关系，但截距 bbb 各不相同（反映不同的功函数 ϕ\phiϕ），而斜率 aaa 在实验误差范围内完全一致。这是一个非平凡的发现。AI 从纯数据中找到了一个"不变量"——一个与材料种类无关的普适常数。如果我们把所有金属的数据放在一起，用 one-hot 编码区分金属种类，让符号回归在更大的特征空间中搜索，PySR 会自动发现公式的结构是 Vs=c⋅ν+diV_s = c \cdot \nu + d_iVs​=c⋅ν+di​：频率前的系数 ccc 不依赖金属种类，而金属种类只影响常数项 did_idi​。

这个结果的物理含义是深远的。斜率 a=h/ea = h/ea=h/e 中包含的是普朗克常数和电子电荷——两个基本的自然常数，与金属是铯、钠还是铜毫无关系。所有金属共享同一个斜率，意味着光与电子之间的能量交换服从一个普适的规则，而这个规则的核心参数 hhh 只取决于光的频率，不取决于材料。AI 可以找到这个数学事实，但它无法告诉我们为什么斜率是普适的。爱因斯坦的光量子假说给出了物理解释：因为光本身是一份一份的，每份能量 hνh\nuhν 完全由频率决定，与光照射的是什么金属无关。Vs=(h/e)ν−ϕ/eV_s = (h/e)\nu - \phi/eVs​=(h/e)ν−ϕ/e 不只是一个拟合公式，它是一个关于光的本性的物理陈述。

这正是"发现公式"与"理解公式"之间的根本区别。在黑体辐射中，AI 发现 1/(ex−1)1/(e^x - 1)1/(ex−1) 需要在非线性函数空间中搜索，是一个复杂度为 6 的表达式；而在光电效应中，AI 发现的 Vs=aν+bV_s = a\nu + bVs​=aν+b 只是一条直线，复杂度仅为 3。从计算角度看，光电方程比普朗克公式"容易"得多。但从物理角度看，爱因斯坦从这条简单的直线中读出的信息远比公式本身丰富：光是量子化的。普朗克只是假设振子的能量是离散的，爱因斯坦则把量子化从物质推广到了光本身——而这个革命性的洞见，是任何回归算法都无法自动生成的。AI 能找到规律，但理解规律的"为什么"，至少在目前，仍然需要人类的物理直觉。

下面的代码演示了这一过程：用模拟的密立根实验数据进行线性拟合，直观展示不同金属的 VsV_sVs​-ν\nuν 关系和普适斜率。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Heiti TC', 'Noto Sans CJK SC', 'SimHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False

# 物理常数
h = 6.626e-34    # 普朗克常数 (J·s)
e_charge = 1.602e-19    # 电子电荷 (C)
c = 3.0e8        # 光速 (m/s)

# 几种金属的功函数 (eV)
metals = {
    '铯 (Cs)':   {'phi': 2.14, 'color': '#e41a1c'},
    '钾 (K)':    {'phi': 2.30, 'color': '#ff7f00'},
    '钠 (Na)':   {'phi': 2.75, 'color': '#4daf4a'},
    '锌 (Zn)':   {'phi': 4.33, 'color': '#377eb8'},
    '银 (Ag)':   {'phi': 4.73, 'color': '#984ea3'},
}

fig, axes = plt.subplots(1, 2, figsize=(14, 5.5))

# --- 左图: eV_s vs 频率 ---
ax = axes[0]
nu = np.linspace(0, 2.5e15, 1000)

for name, info in metals.items():
    phi_J = info['phi'] * e_charge
    nu_0 = phi_J / h
    V_s = (h * nu - phi_J) / e_charge
    V_s_plot = np.where(nu >= nu_0, V_s, np.nan)

    ax.plot(nu * 1e-14, V_s_plot, color=info['color'], linewidth=2,
            label=f"{name}, $\\phi$ = {info['phi']:.2f} eV")
    ax.plot(nu_0 * 1e-14, 0, 'o', color=info['color'], markersize=7, zorder=5)

ax.axhline(y=0, color='gray', linestyle='-', alpha=0.3)
ax.set_xlabel('频率 $\\nu$ ($\\times 10^{14}$ Hz)')
ax.set_ylabel('遏止电压 $V_s$ (V)')
ax.set_title('爱因斯坦光电效应方程: $eV_s = h\\nu - \\phi$')
ax.legend(fontsize=8.5, loc='upper left')
ax.set_xlim(0, 25)
ax.set_ylim(-1, 8)

ax.annotate('斜率 $= h/e$\n(普适常数, 与金属无关)',
            xy=(18, 4.5), fontsize=10, color='black',
            bbox=dict(boxstyle='round,pad=0.3', facecolor='lightyellow', alpha=0.8))

# --- 右图: 不同光强下的光电流 vs 电压 ---
ax2 = axes[1]
V = np.linspace(-3, 5, 500)
V_s_val = 1.5

def photocurrent(V, V_s, I_sat):
    I = np.zeros_like(V)
    mask = V >= -V_s
    I[mask] = I_sat * (1 - np.exp(-(V[mask] + V_s) / 0.3))
    I[V > 1] = I_sat
    return I

intensities = [1.0, 2.0, 3.0]
colors_I = ['#66c2a5', '#fc8d62', '#8da0cb']
labels_I = ['低光强 $I_0$', '中光强 $2I_0$', '高光强 $3I_0$']

for I_sat, col, lab in zip(intensities, colors_I, labels_I):
    I = photocurrent(V, V_s_val, I_sat)
    ax2.plot(V, I, color=col, linewidth=2, label=lab)

ax2.axvline(x=-V_s_val, color='red', linestyle='--', alpha=0.7, linewidth=1.5)

左图展示了不同金属的遏止电压与入射光频率的线性关系。每条直线的斜率都等于 h/eh/eh/e，这是一个与金属种类无关的普适常数。各直线与横轴的交点就是该金属的截止频率 ν0=ϕ/h\nu_0 = \phi/hν0​=ϕ/h，功函数 ϕ\phiϕ 越大，截止频率越高，需要更短波长(更高能量)的光才能产生光电子。右图展示了固定光频率下，改变光强时光电流随外加电压的变化曲线。增大光强使饱和光电流成比例增大(更多光子产生更多光电子)，但遏止电压始终不变(每个光子的能量不随光强改变)。

下面的代码进一步展示如何通过测量遏止电压与频率的数据来"反向提取"普朗克常数 hhh，模拟密立根 1916 年的经典实验。

import numpy as np
from scipy import stats

# 模拟密立根实验数据: 钠金属 (phi = 2.75 eV)
wavelengths_nm = np.array([200, 250, 300, 350, 400, 450])
phi_Na = 2.75

# 计算理论遏止电压
hc_eVnm = 1240.0
photon_energy_eV = hc_eVnm / wavelengths_nm
V_s_theory = photon_energy_eV - phi_Na

# 只保留能产生光电子的数据 (V_s > 0)
mask = V_s_theory > 0
wavelengths_valid = wavelengths_nm[mask]
nu_valid = 3e8 / (wavelengths_valid * 1e-9)
V_s_valid = V_s_theory[mask]

# 加入少量模拟实验噪声
np.random.seed(42)
V_s_exp = V_s_valid + np.random.normal(0, 0.02, len(V_s_valid))

# 线性回归: V_s = (h/e) * nu - phi/e
slope, intercept, r_value, p_value, std_err = stats.linregress(nu_valid, V_s_exp)

h_measured = slope * 1.602e-19
phi_measured = -intercept

print("=" * 50)
print("模拟密立根实验: 从光电效应数据提取 h")
print("=" * 50)
print(f"\n实验数据 (钠金属):")
print(f"{'波长 (nm)':>10} {'频率 (10¹⁴ Hz)':>18} {'遏止电压 (V)':>15}")
print("-" * 45)
for lam, nu, vs in zip(wavelengths_valid, nu_valid, V_s_exp):
    print(f"{lam:>10.0f} {nu*1e-14:>18.2f} {vs:>15.3f}")

print(f"\n线性拟合: V_s = ({slope:.4e}) × ν + ({intercept:.4f})")
print(f"拟合优度: R² = {r_value**2:.6f}")
print(f"\n提取的普朗克常数: h = {h_measured:.4e} J·s")
print(f"标准值:           h = 6.6261e-34 J·s")
print(f"相对偏差: {abs(h_measured - 6.6261e-34)/6.6261e-34 * 100:.2f}%")
print(f"\n提取的功函数:     φ = {phi_measured:.3f} eV")
print(f"标准值:           φ = {phi_Na:.2f} eV")

这段代码模拟了密立根实验的数据处理过程。通过对遏止电压与频率的线性拟合，斜率直接给出 h/eh/eh/e，从而提取出普朗克常数；截距(取负值)给出金属的功函数。密立根 1916 年正是通过这一方法得到了与普朗克从黑体辐射独立给出的值高度一致的 hhh，从而为爱因斯坦的光量子假说提供了无可辩驳的实验支持——尽管密立根本人在哲学上始终对光量子概念心存疑虑。

  1. 爱因斯坦的光量子假说成功解释了光电效应，但光的干涉和衍射实验清楚地表明光具有波动性。一个实体如何同时表现出粒子性和波动性？这种"波粒二象性"是否意味着光"有时是波、有时是粒子"，还是说我们需要一个全新的概念框架？
