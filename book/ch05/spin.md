# 5.1 电子自旋

## 施特恩-格拉赫实验

二十世纪初的物理学家们已经知道，原子可以拥有磁矩，这一磁矩源自带电粒子的角动量。然而，角动量在空间中的取向究竟是连续分布的还是量子化的，在当时仍然是一个悬而未决的问题。为了回答这个根本性的问题，奥托·施特恩(Otto Stern)在 1921 年提出了一个精妙的实验方案，并于次年与瓦尔特·格拉赫(Walther Gerlach)在法兰克福大学的实验室里将其付诸实现。

施特恩-格拉赫实验的构思极为精巧。他们首先在一个小型电炉中加热银，使银原子蒸发并从炉口的小孔喷出，经过一系列狭缝准直后形成一束方向性良好的原子束。这束银原子接下来穿过一对经过特殊设计的磁极——一个磁极的截面是尖锐的楔形，另一个则有一道凹槽，这种不对称的几何构型使得磁极之间的磁场在竖直方向上具有很大的梯度。也就是说，磁场的强度在空间中并不均匀，从一侧到另一侧有系统性的变化。穿过这片非均匀磁场之后，原子束到达一块冷的玻璃收集板，银原子沉积在板上形成可观察的图案。

如果银原子具有磁矩 $\mu$，那么在不均匀磁场中它会受到一个与磁矩方向有关的力 $F_z = \mu_z \frac{\partial B}{\partial z}$。按照经典物理学的预期，原子磁矩的方向应当是完全随机的，$\mu_z$ 可以连续地取从 $-\mu$ 到 $+\mu$ 之间的任意值。因此，从经典角度出发，人们预期在收集板上看到的应该是一条连续展宽的条纹——磁矩朝上的原子向上偏转多一些，磁矩朝下的原子向下偏转多一些，中间还有各种取向的原子对应着各种不同程度的偏转。然而，当格拉赫在 1922 年 2 月取下收集板仔细观察时，他看到的完全出乎所有人的预料：银原子束干净利落地分裂为两束，在收集板上留下两条清晰分离的沉积带，中间几乎没有任何银原子。两束！不是三束，不是五束，恰好两束。这意味着 $\mu_z$ 不是连续变化的，而是只取两个离散的值。

这个结果在当时引起了巨大的震动。人们最初试图用轨道角动量的量子化来解释这一现象，但很快发现这条路行不通。银原子的基态电子构型是 $[\text{Kr}]4d^{10}5s^1$，最外层那个唯一的价电子处于 $5s$ 轨道上，其轨道量子数 $l=0$。$l=0$ 意味着轨道角动量为零，相应的磁量子数 $m_l$ 也只能取零这一个值。如果磁矩完全来自轨道运动，原子束根本不应该发生任何偏转，更不用说分裂为两束了。这个谜团在物理学界悬而未决了三年之久。

1925 年秋天，两位年轻的荷兰物理学家——乔治·乌伦贝克(George Uhlenbeck)和塞缪尔·古德施密特(Samuel Goudsmit)——在他们的导师保罗·埃伦费斯特(Paul Ehrenfest)的鼓励下，提出了一个大胆的假说。他们认为，电子除了因绕核运动而产生的轨道角动量之外，还拥有一种与空间运动无关的内禀角动量，他们称之为"自旋"(spin)。这个自旋角动量对应的量子数为 $s = 1/2$，正好给出了两个可能的磁量子数取值 $m_s = +1/2$ 和 $m_s = -1/2$，完美地解释了施特恩-格拉赫实验中原子束分裂为两束的观测结果。据说乌伦贝克和古德施密特起初对自己想法的大胆程度感到不安，曾想撤回已经交给埃伦费斯特的论文，但埃伦费斯特告诉他们论文已经寄出去了，并安慰说："你们还年轻，承受得起犯一个错误。"事实证明，这根本不是一个错误。

自旋角动量的大小由量子数 $s = 1/2$ 决定：

$$
|\mathbf{S}| = \sqrt{s(s+1)}\hbar = \frac{\sqrt{3}}{2}\hbar
$$

而自旋在 $z$ 方向上的分量只能取两个值：

$$
S_z = m_s\hbar, \quad m_s = +\frac{1}{2} \text{ (自旋向上) 或 } -\frac{1}{2} \text{ (自旋向下)}
$$

自旋产生的磁矩为：

$$
\mu_s = -g_s \frac{e}{2m_e} S_z = -g_s m_s \mu_B
$$

其中 $g_s \approx 2$ 是电子的自旋 $g$ 因子(朗德 $g$ 因子)。这个值约为 2 的事实在经典理论中无法得到任何解释——对于轨道运动，对应的 $g$ 因子恰好为 1。$g_s \approx 2$ 的来源必须追溯到保罗·狄拉克(Paul Dirac)在 1928 年建立的相对论量子力学方程。狄拉克方程作为薛定谔方程的相对论推广，将自旋和它的反常 $g$ 因子作为方程的自然推论给出，而不需要任何额外的假设。量子电动力学(QED)进一步给出了 $g_s$ 对精确值 2 的微小偏离：$g_s = 2.002\,319\,304\,362...$，这一理论预测与实验测量吻合到小数点后十二位，成为物理学史上最精确的理论预言之一。

"自旋"这个名字容易使人产生一种直觉上的图像——电子像一个微小的陀螺一样在自身轴线上旋转。但这个图像是严重误导性的。如果将电子视为一个具有经典半径(约 $10^{-15}$ m)的带电球体，要产生实验观测到的角动量大小 $\sim \hbar/2$，可以估算出球体表面的线速度需要远远超过光速，这在物理上是不可能的。更根本地说，电子在当代物理学中被视为一个点粒子(至少在目前实验能探测到的最小尺度上是如此)，一个数学上无大小的点谈不上有什么"绕自身轴旋转"的可能。自旋是一种纯粹的量子力学性质，没有任何经典对应物。它是电子的内禀属性，就像质量和电荷一样——电子一"诞生"就携带着 $s = 1/2$ 的自旋，这个值永远不会改变，也无法被"加速"或"减速"。

## 硅基视角：量子比特(Qubit)

自旋的发现为电子增加了一个二值的元数据(Metadata)：它并不影响电子在空间中的轨道运动(至少在非相对论近似下如此)，但却给每一个量子态额外附加了一个标签。在自旋被纳入描述之前，一个电子的量子态由三个量子数 $(n, l, m)$ 唯一确定；现在则需要四个量子数 $(n, l, m, m_s)$ 才能完整地指定一个状态。用量子力学的记号，完整的量子态可以写成轨道部分与自旋部分的直积 $|\psi\rangle = |n, l, m\rangle \otimes |m_s\rangle$。自旋向上的态 $|m_s = +1/2\rangle$ 通常简写为 $|\!\uparrow\rangle$，自旋向下的态 $|m_s = -1/2\rangle$ 简写为 $|\!\downarrow\rangle$。

从计算机科学的角度来看，电子自旋是量子比特(qubit)的最自然的物理实现之一。一个经典比特只能处于 0 或 1 两种状态之一，在任意时刻它的状态都是完全确定的，可以被无损地读取，也可以被任意复制。而一个量子比特则截然不同。电子的自旋态可以是 $|\!\uparrow\rangle$ 和 $|\!\downarrow\rangle$ 的任意叠加：

$$
|\psi\rangle = \alpha|↑\rangle + \beta|↓\rangle, \quad |\alpha|^2 + |\beta|^2 = 1
$$

复数系数 $\alpha$ 和 $\beta$ 蕴含了无穷多种可能的叠加方式，使得一个 qubit 所承载的信息在某种意义上远比一个经典比特丰富。然而，当我们对自旋进行测量时，叠加态不可逆地坍缩为 $|\!\uparrow\rangle$ 或 $|\!\downarrow\rangle$ 中的某一个，概率分别为 $|\alpha|^2$ 和 $|\beta|^2$。这种测量的破坏性是量子力学的基本特征：读取一个 qubit 的"值"会不可避免地改变它的状态。更进一步，量子力学的不可克隆定理(no-cloning theorem)严格证明了不存在任何物理过程能够完美复制一个未知的量子态。经典比特可以随意复制和广播，而量子信息一旦被创造，就不可能被忠实地复制到另一个系统上。这些看似限制性的特征，反而构成了量子计算和量子密码学的基础——正因为量子态不可克隆，量子密钥分发才能实现理论上无条件安全的通信。

```{code-cell} ipython3
import numpy as np

# 自旋态表示
spin_up = np.array([1, 0])    # |↑⟩
spin_down = np.array([0, 1])  # |↓⟩

# 叠加态: |ψ⟩ = (|↑⟩ + |↓⟩) / √2
psi = (spin_up + spin_down) / np.sqrt(2)

# 泡利矩阵 (自旋算符)
sigma_x = np.array([[0, 1], [1, 0]])
sigma_y = np.array([[0, -1j], [1j, 0]])
sigma_z = np.array([[1, 0], [0, -1]])

# 测量 S_z 的期望值
Sz_expect = np.real(psi.conj() @ sigma_z @ psi)
print(f"⟨S_z⟩ = {Sz_expect} ℏ/2")  # 输出: 0(等概率上下)

# 测量 S_z 得到 +ℏ/2 的概率
prob_up = abs(psi @ spin_up.conj())**2
print(f"P(↑) = {prob_up}")  # 输出: 0.5
```

## 思考题

1. 为什么自旋不能用经典旋转来解释？如果把电子当作经典的旋转带电球体，会遇到什么困难？

2. 施特恩-格拉赫实验中原子束分裂为两束，这说明自旋在空间中的取向是"量子化"的。但如果我们沿不同方向测量，每次都只得到两个值，这些测量结果之间有什么关系？

3. 自旋是一种"内禀角动量"，与空间运动无关。这种性质如何与相对论联系起来？狄拉克方程为什么能"自然地"给出自旋？

4. 两个自旋1/2的粒子可以组合成自旋0(单态)或自旋1(三重态)。这种角动量耦合有什么物理意义？与化学键的形成有什么关系？
