# 5.1 隐藏的比特

> **Algorithm Goal:** 理解自旋作为电子的内禀量子数，它如何为量子态增加一个二值自由度，以及它与经典旋转的根本区别。

---

## Carbon Story：施特恩-格拉赫实验

### 实验设计

1922 年，施特恩(Otto Stern)和格拉赫(Walther Gerlach)设计了一个精巧的实验：

1. 将银原子蒸发，形成原子束。
2. 让原子束通过一个**不均匀磁场**(磁场强度在空间中有梯度)。
3. 观察原子束在屏幕上的沉积图案。

### 经典预期 vs 实验结果

如果银原子具有磁矩 $\mu$，在不均匀磁场中会受到力 $F_z = \mu_z \frac{\partial B}{\partial z}$。

- **经典预期**：原子磁矩的方向是随机的，$\mu_z$ 可以取从 $-\mu$ 到 $+\mu$ 的连续值。所以原子束应该在屏幕上形成**连续的展宽条纹**。
- **实验结果**：原子束**恰好分裂为两束**，对应 $\mu_z$ 只有两个离散值。

两束！不是三束，不是五束，恰好两束。

### 乌伦贝克-古德施密特假说

对于银原子的最外层电子(5s)，$l=0$，轨道磁矩为零。但实验明确显示了非零磁矩，而且只有两个取值。

1925 年，乌伦贝克(George Uhlenbeck)和古德施密特(Samuel Goudsmit)提出：**电子具有内禀角动量**，称为**自旋(spin)**，自旋量子数 $s = 1/2$。

自旋角动量：

$$
|\mathbf{S}| = \sqrt{s(s+1)}\hbar = \frac{\sqrt{3}}{2}\hbar
$$

$z$ 分量只有两个取值：

$$
S_z = m_s\hbar, \quad m_s = +\frac{1}{2} \text{ (自旋向上) 或 } -\frac{1}{2} \text{ (自旋向下)}
$$

### 自旋磁矩

自旋产生的磁矩为：

$$
\mu_s = -g_s \frac{e}{2m_e} S_z = -g_s m_s \mu_B
$$

其中 $g_s \approx 2$ 是电子的 **$g$ 因子**(朗德 $g$ 因子)，这个值无法用经典理论解释，它来自狄拉克方程(相对论量子力学)。

### 自旋不是经典旋转

"自旋"这个名字容易误导人以为电子在"自转"。但如果把电子当作经典带电球体，要产生实验观测到的角动量，表面线速度需要超过光速。

**自旋是纯粹的量子力学性质，没有经典对应物。** 它是电子的内禀属性，就像质量和电荷一样。

## Silicon Perspective：量子比特(Qubit)

### Header 信息

自旋为电子增加了一个**二值元数据(Metadata)**：它不影响电子的轨道运动(在非相对论近似下)，但给每个量子态附加了一个额外的标签。

完整的量子态现在需要**四个**量子数：$(n, l, m, m_s)$。

```
量子态 = 轨道信息 + 自旋信息
|ψ⟩ = |n, l, m⟩ ⊗ |m_s⟩

自旋态:
  |↑⟩ = |m_s = +1/2⟩   →  "spin up"    →  比特 1
  |↓⟩ = |m_s = -1/2⟩   →  "spin down"  →  比特 0
```

### Qubit：量子计算的基本单元

电子自旋是**量子比特(Qubit)**的最自然实现之一。与经典比特的根本区别：

| | 经典比特 | 量子比特(Qubit)|
|---|---------|-----------------|
| 状态 | 0 或 1 | $\alpha\|↑⟩ + \beta\|↓⟩$(叠加态) |
| 读取 | 非破坏性 | 破坏性(坍缩)|
| 复制 | 可以 | 不可以(不可克隆定理)|
| 信息容量 | 1 bit | 1 qubit(无穷多叠加态)|

自旋的叠加态：

$$
|\psi\rangle = \alpha|↑\rangle + \beta|↓\rangle, \quad |\alpha|^2 + |\beta|^2 = 1
$$

测量之前，自旋"既是上又是下"(叠加态)。测量之后，坍缩到 $|↑⟩$ 或 $|↓⟩$ 之一，概率分别为 $|\alpha|^2$ 和 $|\beta|^2$。

```{code-cell} ipython3
import numpy as np

# 自旋态表示
spin_up = np.array([1, 0])    # |↑⟩
spin_down = np.array([0, 1])  # |↓⟩

# 叠加态: |ψ⟩ = (|↑⟩ + |↓⟩) / √2
psi = (spin_up + spin_down) / np.sqrt(2)

# 泡利矩阵 (自旋算符)
sigma_x = np.array([[0, 1], [1, 0]])
sigma_y = np.array([[0, -1j], [1j, 0]])
sigma_z = np.array([[1, 0], [0, -1]])

# 测量 S_z 的期望值
Sz_expect = np.real(psi.conj() @ sigma_z @ psi)
print(f"⟨S_z⟩ = {Sz_expect} ℏ/2")  # 输出: 0(等概率上下)

# 测量 S_z 得到 +ℏ/2 的概率
prob_up = abs(psi @ spin_up.conj())**2
print(f"P(↑) = {prob_up}")  # 输出: 0.5
```
