## 第二题：MCMC 贝叶斯分析 COBE/FIRAS 数据 (25 分)

1989 年 11 月，NASA 发射了宇宙背景探测者(COBE)卫星。卫星上搭载的远红外绝对分光光度计(FIRAS)以前所未有的精度测量了宇宙微波背景辐射(CMB)的频谱。1990 年 1 月，当 FIRAS 团队的 John Mather 在美国天文学会会议上展示 CMB 频谱与理论黑体曲线的吻合程度时，全场起立鼓掌——这是天文学史上罕见的时刻。FIRAS 最终确定 CMB 温度为 $T = 2.725 \pm 0.002$ K，光谱偏离黑体的程度不超过万分之一。Mather 因此获得 2006 年诺贝尔物理学奖。

具体方法：定义升温后验(tempered posterior)

$$p_\beta(\theta) \propto [L(\theta)]^\beta \pi(\theta), \quad \beta \in [0, 1]$$

$$\ln Z = \int_0^1 \langle \ln L \rangle_\beta \, d\beta \approx \sum_{i} \frac{1}{2}(\langle \ln L \rangle_{\beta_i} + \langle \ln L \rangle_{\beta_{i+1}})(\beta_{i+1} - \beta_i)$$

| $\ln B_{12}$ | 证据强度 |

| 0 - 1 | 不值一提 |
| 1 - 2.5 | 显著 |
| 2.5 - 5 | 强 |
| > 5 | 决定性 |

## 第三题：正则化与量子化的数值实验 (15 分)

在机器学习中，正则化(regularization)是对抗过拟合的核心技术：通过在损失函数中添加惩罚项，限制模型复杂度，迫使模型学到更"简洁"的解。L1 正则化(Lasso)鼓励稀疏解，L2 正则化(Ridge)鼓励小而均匀的权重。这些手段看似纯粹是工程技巧，与基础物理毫无关系。

然而，课堂上硅基视角的讨论揭示了一个深刻的类比：经典物理中的紫外灾变——瑞利-金斯公式预言黑体辐射能量在高频处趋向无穷——本质上就是一个"过拟合"问题。经典理论对每个频率模式赋予相同的能量 $k_BT$(能量均分定理)，高频模式数目按 $\nu^2$ 增长，总能量不可避免地发散。普朗克引入的能量量子化 $E = nh\nu$ 在物理上等价于一种频率相关的正则化：$h\nu/k_BT$ 越大，该模式被"冻结"(freeze out)的程度越高，高频贡献被指数衰减地压制。

本题将这一类比转化为可执行的数值实验。你将构造一个模拟"能量分配"的优化问题，亲手实现 L1、L2 和"量子"正则化，观察它们如何将发散的经典解修正为收敛的量子解。更进一步，你将尝试从数据中"学习"出最优的正则化方案，看看机器学习能否自动发现类似量子化的数学结构。

### 3.1 构造"黑体辐射"优化问题 (6 分)

考虑一个 $N = 200$ 维的能量分配问题。每个维度代表一个频率模式 $\nu_i$($i = 1, 2, \ldots, N$)，频率从 $\nu_1 = 10^{12}$ Hz 到 $\nu_N = 10^{15}$ Hz 等间隔取值(覆盖红外到紫外波段)。模式密度为 $\rho_i = \nu_i^2 / \sum_j \nu_j^2$(归一化)。我们要求解：

$$\min_{\boldsymbol{w}} \quad \mathcal{L}(\boldsymbol{w}) = -S(\boldsymbol{w}) + \mathcal{R}(\boldsymbol{w})$$

其中 $S(\boldsymbol{w}) = -\sum_i \rho_i [w_i \ln w_i - w_i]$ 是(负)熵项(鼓励均匀分配)，$\mathcal{R}(\boldsymbol{w})$ 是正则化项，$w_i \geq 0$ 是第 $i$ 个模式分配到的"权重"(类比平均能量)。

**要求：**

(a) 实现梯度下降求解器 `gradient_descent(loss_fn, grad_fn, w0, lr, n_steps)`，支持投影到非负约束($w_i \geq 0$)。

(b) 分别用以下四种正则化方案求解，并绘制最优 $\boldsymbol{w}^*$ 随频率的分布曲线(四条曲线画在同一张图上)：

- **无正则化**：$\mathcal{R} = 0$。(预期：$w_i = \text{const}$，类比经典能量均分)
- **L1 正则化**：$\mathcal{R} = \lambda_1 \sum_i \nu_i |w_i|$，取 $\lambda_1 = 0.5$
- **L2 正则化**：$\mathcal{R} = \lambda_2 \sum_i \nu_i^2 w_i^2$，取 $\lambda_2 = 0.1$
- **"量子"正则化**：$\mathcal{R} = \sum_i \rho_i \left[ \frac{h\nu_i}{e^{h\nu_i w_i/k_BT} - 1} - w_i \right]^2$，即惩罚 $w_i$ 偏离普朗克分布的程度(取 $T = 5000$ K)

(c) 计算每种方案下的"总能量"$E_{\text{tot}} = \sum_i \rho_i w_i$，验证无正则化方案发散(或需要截断)，而正则化方案收敛。

## 第四题：多波段恒星测温与 HR 图 (15 分)

天文学家如何测量一颗遥远恒星的表面温度？理论上，维恩位移定律 $\lambda_\text{max}T = b$ 给出了一个简洁的答案——找到光谱峰值波长即可推算温度。但在实际观测中，获取完整的恒星光谱是昂贵的：光谱仪需要将光分散到多个波长通道，每个通道接收的光子数大幅减少，观测时间成倍增加。对于暗弱天体，完整光谱观测几乎不可行。

天文学家的解决方案是测光(photometry)——使用几个标准化的宽波段滤光片(如 Johnson UBVRI 系统)拍摄图像，测量恒星在每个波段的亮度(星等)。Johnson 和 Morgan 在 1953 年建立的 UBV 系统是现代天文测光的基石，后来扩展到红外的 R 和 I 波段。五个波段从紫外(U, 365 nm)到近红外(I, 798 nm)，覆盖了恒星辐射的主要波段。两个波段星等之差称为色指数(color index)，如 $B-V$、$U-B$。色指数的妙处在于它不依赖恒星的距离和大小——无论恒星多远多小，色指数只反映其表面温度。蓝色高温恒星的 $B-V$ 为负值，红色低温恒星的 $B-V$ 为正值。

赫茨普龙-罗素图(HR 图)是天文学中最重要的诊断工具之一。丹麦天文学家赫茨普龙(1911 年)和美国天文学家罗素(1913 年)独立发现，如果将恒星的光度(或绝对星等)对表面温度作图，恒星并非随机分布，而是聚集在几条清晰的带上。绝大多数恒星位于从左上(高温高光度)到右下(低温低光度)的主序带(main sequence)上，这反映了恒星在生命主要阶段的氢核聚变平衡。脱离主序的恒星(如红巨星、白矮星)则处于演化的不同阶段。

本题要求你从五个波段的测光数据出发，通过合成测光和 $\chi^2$ 拟合来确定恒星温度，最终将结果放在 HR 图上讨论恒星的演化状态。

## 第五题：宇宙热历史模拟 (10 分)

我们今天观测到的宇宙微波背景辐射是大爆炸的余晖。在宇宙诞生后约 38 万年(红移 $z \approx 1100$)，宇宙温度降至约 3000 K，电子与质子复合形成中性氢原子，光子不再与物质频繁散射，宇宙变得"透明"——这一时刻称为光子退耦(photon decoupling)或最后散射面(last scattering surface)。此后，这些光子在膨胀的宇宙中自由传播，波长随宇宙尺度因子线性拉伸，温度从约 3000 K 冷却至今天的 2.725 K。

这个冷却过程有一个优美的性质：黑体谱在绝热膨胀下保持黑体形状，只是温度按 $T(z) = T_0(1+z)$ 降低。这意味着今天的 CMB 虽然处于微波波段(峰值波长约 1.1 mm)，但在退耦时刻却处于可见光/近红外波段——如果那时有观测者，天空将是一片均匀的橙红色光芒。追溯宇宙的热历史，就是追溯这片光芒如何从可见光逐渐红移到红外、再到微波的过程。

CMB 温度随宇宙膨胀而降低：$T(z) = T_0(1+z)$，其中 $T_0 = 2.725$ K 是当前温度，$z$ 是红移。

(c) 思考题：如果普朗克常数 $h$ 增大为 $2h$，Wien 位移常数 $b$ 如何变化？维恩位移定律 $\lambda_\text{max} T = b$ 的数值关系有何改变？紫外灾变是否仍然存在？量化会更早还是更晚出现(即 $h\nu/k_BT = 1$ 对应的频率如何变化)？

### 6.2 符号回归：从数据中搜索解析公式 (7 分)

符号回归(Symbolic Regression)与神经网络截然不同：它不是拟合一个黑箱函数，而是在解析表达式的空间中搜索，试图找到一个简洁的数学公式来描述数据。本题使用 PySR 库(`pip install pysr`)。

**关键技巧：使用无量纲变量。** 直接对 $u(\nu, T)$ 做符号回归几乎不可能成功，因为搜索空间太大。但如果我们将问题化为无量纲形式，搜索空间会大幅缩小。定义：

$$x = \frac{h\nu}{k_BT}, \qquad y = \frac{u(\nu,T)}{u_0(\nu)}$$

其中 $u_0(\nu) = 8\pi h\nu^3/c^3$ 是一个已知的频率前因子。那么普朗克公式简化为：

$$y = \frac{1}{e^x - 1}$$

符号回归只需要发现这个单变量函数。

**要求：**

(a) **第一步：发现频率前因子。** 固定一个温度(如 $T = 5000$ K)，生成数据 $\{(\nu_i, u_i)\}$。先尝试对低频区($h\nu \ll k_BT$)的数据做符号回归，搜索 $u$ 与 $\nu$ 的幂律关系。PySR 设置参考：

```python
from pysr import PySRRegressor

model = PySRRegressor(
    niterations=200,
    binary_operators=["+", "-", "*", "/"],
    unary_operators=["exp", "log", "square", "cube"],
    maxsize=20,
    populations=30,
    batching=True,
    batch_size=50,
)

# 低频区数据 (x = hν/kBT < 0.5)
mask = x < 0.5
model.fit(nu[mask].reshape(-1, 1), u[mask])
print(model)  # 期望发现 u ∝ ν² (瑞利-金斯极限)
```

报告 PySR 给出的最佳公式及其复杂度-精度权衡(Pareto 前沿)。

(b) **第二步：发现核心函数 $1/(e^x - 1)$。** 计算无量纲变量 $x = h\nu/k_BT$ 和 $y = u / (8\pi h\nu^3/c^3)$，对多个温度(1000 K 到 10000 K)的数据合并后做符号回归：

```python
# 合并多个温度的数据，全部化为 (x, y)

    niterations=500,
    binary_operators=["+", "-", "*", "/"],
    unary_operators=["exp", "neg"],
    maxsize=15,
    populations=40,
    batching=True,
    batch_size=100,
)
model2.fit(x_all.reshape(-1, 1), y_all)
```

报告 PySR 的 Pareto 前沿，即不同复杂度下的最佳公式。理想情况下应出现 $1/(e^x - 1)$，但也可能出现近似形式如 $e^{-x}/x$ (Wien 近似)。对 Pareto 前沿上的每个公式，绘制其与真实 $1/(e^x-1)$ 的对比图和残差图。

(c) **第三步(如果第二步未找到精确公式)：分段发现。** 分别对 $x < 1$ (低频)和 $x > 3$ (高频)的数据做符号回归。低频区应发现 $y \approx 1/x$(瑞利-金斯极限），高频区应发现 $y \approx e^{-x}$(维恩极限)。讨论如何将两个极限"统一"为完整的普朗克公式。
