# 1.1 电子的发现与基本性质

## 阴极射线与电子的发现

19世纪后半叶，物理学家们对真空放电现象产生了浓厚的兴趣。当在抽成低压的玻璃管两端施加高电压时，会观察到从阴极发出一种射线，使管壁发出荧光。1876年，德国物理学家戈尔德斯坦(Eugen Goldstein)将这种射线命名为"阴极射线"(cathode rays)。阴极射线的本质是什么？这个问题成为当时物理学界激烈争论的焦点，争论持续了近二十年，并沿着国界线将物理学家分成了两个阵营。

德国学派以戈尔德斯坦、赫兹(Heinrich Hertz)和勒纳德(Philipp Lenard)为代表，他们认为阴极射线是一种类似于光的电磁波动，或者说是"以太波"。支持这一观点的证据看起来相当有力。首先，阴极射线能使某些物质发出荧光，这与紫外线的效应非常相似。其次，阴极射线沿直线传播，不受重力影响，这是波动的典型特征。最重要的证据来自赫兹1883年的实验：他试图用带电金属板偏转阴极射线，但没有观察到任何偏转效应。赫兹推断，如果阴极射线是带电粒子，它们应该被电场吸引或排斥；既然没有偏转，那就不可能是带电粒子，因此阴极射线很可能是某种新型的电磁波。1892年，赫兹还发现阴极射线能够穿透薄金属箔，这似乎进一步支持了波动说，因为人们难以想象粒子能够穿过固体金属。

英国学派以克鲁克斯(William Crookes)和汤姆孙为代表，他们坚持认为阴极射线是高速运动的带电粒子流。克鲁克斯早在1879年就提出阴极射线是"辐射物质"(radiant matter)，即某种带电的原子或分子。支持粒子说的证据同样很有说服力。阴极射线能被磁场偏转，而电磁波不会被磁场影响。克鲁克斯在真空管中放入一个马耳他十字形的障碍物，结果在管壁上投下了清晰的阴影，这表明阴极射线像粒子一样沿直线传播并被固体阻挡。更有趣的是，克鲁克斯发现阴极射线能推动管中的小风车叶片转动，说明它们携带动量，这是粒子的特征而非波动的特征。

1895年，法国物理学家让·佩兰(Jean Perrin)进行了一个关键实验，直接证明了阴极射线携带负电荷 {cite}`perrin1895`。佩兰在真空管内放置了一个法拉第筒(一种电荷收集器)，当阴极射线射入法拉第筒时，电计显示筒内积累了负电荷。为了确认电荷确实来自阴极射线而非其他来源，佩兰用磁铁偏转阴极射线使其不再射入法拉第筒，结果电荷积累立即停止；撤去磁场后，电荷积累又恢复了。这个实验无可辩驳地证明了阴极射线携带负电荷。然而，德国学派仍然可以辩称，也许是阴极射线在撞击法拉第筒时产生了某种次级效应才导致电荷积累。

1897年，剑桥大学卡文迪许实验室的约瑟夫·约翰·汤姆孙(Joseph John Thomson)通过一系列精巧的实验，最终解决了这个争论 {cite}`thomson1897`。汤姆孙意识到赫兹1883年实验失败的真正原因：不是阴极射线不能被电场偏转，而是真空度不够。当真空管中残留有气体时，强电场会使气体电离，产生的离子会中和电场，形成类似法拉第笼的屏蔽效应。汤姆孙改进了抽真空技术，将真空度提高到前所未有的水平，终于成功观察到了电场对阴极射线的偏转。这个结果决定性地证明了阴极射线是带电粒子，因为电磁波不可能被电场偏转。

汤姆孙接下来进行了一个更为精巧的实验。他让阴极射线同时受到互相垂直的电场和磁场作用，通过调节电场和磁场的强度，可以使两者对粒子的作用力相互抵消，从而让射线不发生偏转。设电场强度为 $E$，磁场强度为 $B$，粒子速度为 $v$，则电场力 $eE$ 与磁场力 $evB$ 平衡的条件是 $eE = evB$，由此可以得到粒子的速度 $v = E/B$。然后，撤去电场只保留磁场，粒子将在洛伦兹力的作用下做圆周运动。根据牛顿第二定律 $evB = mv^2/r$，可以得到粒子的荷质比

$$
\frac{e}{m} = \frac{v}{Br} = \frac{E}{B^2 r}
$$

汤姆孙的实验结果令人震惊。他发现阴极射线粒子的荷质比约为 $1.76 \times 10^{11}$ C/kg，这个数值比当时已知的任何离子的荷质比都要大得多。以氢离子为例，其荷质比约为 $9.6 \times 10^7$ C/kg，比阴极射线粒子小了近两千倍。更重要的是，无论使用什么材料做阴极，无论管中残留什么气体，测得的荷质比都是相同的。这意味着阴极射线粒子是一种普遍存在于所有物质中的基本组成成分。汤姆孙将这种粒子命名为"电子"（electron），这个名称来源于希腊语中的"琥珀"一词，因为古人最早在摩擦琥珀时发现了静电现象。

汤姆孙的发现具有划时代的意义。它首次证明了原子不是不可分割的，而是具有内部结构的。电子从各种不同的原子中被释放出来，说明电子是所有原子的共同组成部分。这个发现不仅改变了人们对物质本质的认识，也开启了探索原子内部结构的新时代。

## 电子电荷的精确测定

汤姆孙的实验测定了电子的荷质比 $e/m$，但要分别确定电子的电荷 $e$ 和质量 $m$，还需要独立测量其中一个量。这个任务由汤姆孙的学生罗伯特·密立根（Robert Millikan）在1909年至1913年间完成，他发展的"油滴实验"成为物理学史上最精巧的实验之一。

密立根实验的基本思想是让带电油滴悬浮在电场中。当油滴受到的电场力恰好与重力平衡时，油滴将静止悬浮。设油滴的电荷为 $q$，质量为 $m_d$，电场强度为 $E$，平衡条件为 $qE = m_d g$。然而，直接测量微小油滴的质量是非常困难的，密立根采用了一个巧妙的方法来解决这个问题。

```{figure} millikan-apparatus.png
:name: fig-millikan-apparatus
:width: 80%
:align: center

密立根油滴实验装置示意图。雾化器将油喷射成微小油滴，油滴通过上极板中心的小孔落入平行极板电容器之间。可调高压电源在极板间产生匀强电场，用于平衡油滴的重力。光源从侧面照亮油滴，使其在显微镜中像星星一样闪亮可见。X射线源用于电离空气，使油滴带上或改变电荷，从而可以在同一油滴上进行多次测量。
```

密立根的方法是观察油滴在无电场时的匀速下落过程。当油滴在空气中下落时，它受到重力和空气阻力的作用。空气阻力由斯托克斯公式给出：$f = 6\pi\eta r v$，其中 $\eta$ 是空气的粘滞系数，$r$ 是油滴半径，$v$ 是下落速度。这个公式由英国物理学家乔治·斯托克斯(George Gabriel Stokes)于1851年在研究摆的运动时推导得出 {cite}`stokes1851`，它描述了低雷诺数条件下球形物体在粘性流体中受到的阻力。当油滴达到匀速下落时，重力等于阻力加上浮力：

$$
\frac{4}{3}\pi r^3 \rho g = 6\pi\eta r v_1 + \frac{4}{3}\pi r^3 \rho_0 g
$$

其中 $\rho$ 是油的密度，$\rho_0$ 是空气密度，$v_1$ 是无电场时的匀速下落速度。由此可以求出油滴半径 $r$，进而求出油滴质量。然后施加电场使油滴匀速上升，测量上升速度 $v_2$，根据力的平衡条件可以求出油滴的电荷 $q$。

密立根实验的精妙之处不仅在于测量方法的巧妙设计，更在于对实验细节的精心控制。他使用钟表油代替普通油滴，因为钟表油不易挥发，可以保持油滴大小的稳定。他在密闭容器中进行实验，以避免空气对流的干扰。他使用X射线照射来改变油滴的电荷，从而可以在同一个油滴上多次测量不同电荷值。

然而，上述分析建立在多个理想化假设之上，真实情况要复杂得多。斯托克斯公式假设油滴是完美的球形，流体是不可压缩的连续介质。但密立根实验中的油滴半径约为 $10^{-6}$ m (1微米)，已经与空气分子的平均自由程(约 $6.8 \times 10^{-8}$ m)可以比拟。在这个尺度上，空气不再能被视为连续介质，分子的离散性开始显现，斯托克斯公式需要修正。坎宁安(Cunningham)首先推导出了这一修正因子，密立根随后通过实验验证并精确标定了它。对于半径约1微米的油滴，坎宁安修正因子约为1.1，如果忽略这一修正，电荷测量值将偏差约10%。此外，微小油滴还受到布朗运动的影响，空气分子的随机碰撞会使油滴的运动产生涨落，给速度测量带来额外的不确定性。密立根在1913年发表的论文标题就明确指出了这一点：《论基本电荷与阿伏伽德罗常数》{cite}`millikan1913`。这个实验不仅测定了电子电荷，同时也标定了流体力学中斯托克斯定律的适用范围和修正方法，可谓一举两得。

密立根对数千个油滴进行了测量，发现一个惊人的规律：所有油滴的电荷都是某个最小值的整数倍。这个最小值就是电子电荷的大小。他得到的结果是 $e = 1.592 \times 10^{-19}$ C，与现代精确值 $e = 1.602 \times 10^{-19}$ C 非常接近。这个实验不仅精确测定了电子电荷，更重要的是证明了电荷的量子化：电荷不能取任意值，只能是基本电荷的整数倍。

结合汤姆孙测得的荷质比和密立根测得的电荷值，可以计算出电子的质量：

$$
m_e = \frac{e}{e/m} = \frac{1.602 \times 10^{-19}}{1.76 \times 10^{11}} = 9.11 \times 10^{-31} \text{ kg}
$$

这个质量只有氢原子质量的约 1/1836，说明电子是一种极轻的粒子。原子的绝大部分质量不在电子身上，而是集中在原子的另一部分——这一部分是什么，要等到卢瑟福的散射实验才能揭晓。

## 阿伏伽德罗常数与原子实在性之争

阿伏伽德罗常数 $N_A$ 是连接宏观世界和微观世界的重要桥梁，它的定义是一摩尔任何物质所含的基本单元数目。然而，这个看似简单的定义背后隐藏着一段曲折的历史：在相当长的时间里，原子和分子是否真实存在本身就是一个激烈争论的问题。

1811年，意大利物理学家阿伏伽德罗(Amedeo Avogadro)提出了一个大胆的假说：在相同的温度和压强下，相同体积的任何气体都含有相同数目的分子。这个假说为化学计量学提供了理论基础，但阿伏伽德罗本人在1856年去世时，他的假说仍未被广泛接受。问题的核心在于：分子真的存在吗？还是它只是一个方便计算的数学工具？

19世纪末，物理学界围绕原子是否真实存在展开了激烈的争论。以马赫(Ernst Mach)和奥斯特瓦尔德(Wilhelm Ostwald)为首的"能量学派"认为，物质的本质是能量，原子和分子只是人为构造的概念，用于简化热力学计算，但并不对应真实的物理实体。马赫曾直言不讳地质问："有谁见过原子？"奥斯特瓦尔德则试图用纯粹的能量关系来取代原子假说。站在对立面的是玻尔兹曼(Ludwig Boltzmann)，他坚信原子的真实性，并用统计力学的方法将宏观热力学与微观原子运动联系起来。1895年的吕贝克科学会议上，玻尔兹曼与奥斯特瓦尔德进行了著名的辩论。当时在场的索末菲(Arnold Sommerfeld)后来回忆道："玻尔兹曼与奥斯特瓦尔德的争论，从外表到内容，都像是一头公牛与一位灵巧的剑客之间的搏斗。但公牛战胜了斗牛士，玻尔兹曼的论证占了上风。"尽管如此，原子的实在性问题仍未得到最终解决。

在这场争论的背景下，测定阿伏伽德罗常数就不仅仅是一个技术问题，而是关乎原子是否存在的根本问题。如果能够精确测定这个常数，并且用不同的方法得到一致的结果，那将是原子真实存在的有力证据。1865年，奥地利物理学家洛施密特(Josef Loschmidt)首次尝试估算分子的数目 {cite}`loschmidt1865`。他利用气体动理论，结合气体分子平均自由程的实验数据，估算出标准状态下每立方厘米气体中约含 $1.83 \times 10^{18}$ 个分子。虽然这个数值比现代值低了一个数量级，但洛施密特的工作首次表明阿伏伽德罗常数是一个极大的数，而分子是极小的。

真正的突破来自1905年爱因斯坦关于布朗运动的理论 {cite}`einstein1905brownian`。布朗运动是指悬浮在液体中的微小颗粒(如花粉)呈现的永不停息的随机运动，这一现象早在1827年就被植物学家布朗观察到，但一直没有得到满意的解释。爱因斯坦指出，如果液体是由大量不断运动的分子组成的，那么悬浮颗粒受到分子的随机碰撞，就会表现出布朗运动。他推导出布朗粒子均方位移与时间的关系：

$$
\langle x^2 \rangle = \frac{RT}{3\pi\eta a N_A} t
$$

其中 $R$ 是气体常数，$T$ 是温度，$\eta$ 是液体粘度，$a$ 是颗粒半径。这个公式的关键之处在于，它将可观测的宏观量(颗粒的位移)与微观常数(阿伏伽德罗常数)联系起来。如果原子不存在，布朗运动就不应该满足这个规律。

法国物理学家佩兰(我们在前面已经提到他1895年证明阴极射线带负电)在1908年至1913年间进行了一系列精密实验，验证了爱因斯坦的理论。他用超显微镜观察悬浮在水中的乳胶颗粒，测量它们的位移，统计分析后得到阿伏伽德罗常数。更重要的是，佩兰用多种不同的方法测定阿伏伽德罗常数，包括布朗运动的平移、布朗运动的转动、沉降平衡等，所有方法得到的结果都高度一致。这种一致性有力地证明了原子和分子的真实存在。佩兰在1913年的著作《原子》中总结道："原子假说因此取得了胜利。" {cite}`perrin1913atoms`面对佩兰实验的证据，即使是最顽固的怀疑论者奥斯特瓦尔德也在1908年承认了原子的存在。佩兰因"关于物质不连续结构的研究"获得了1926年的诺贝尔物理学奖。

除了布朗运动，还有其他方法可以测定阿伏伽德罗常数。法拉第电解定律提供了一种途径：在电解过程中，沉积或释放一摩尔任何一价物质所需的电量是一个常数，称为法拉第常数 $F = 96485$ C/mol。这个常数等于一摩尔电子所携带的总电荷，即 $F = N_A e$。如果已知电子电荷 $e$，就可以计算出阿伏伽德罗常数：

$$
N_A = \frac{F}{e} = \frac{96485}{1.602 \times 10^{-19}} = 6.02 \times 10^{23} \text{ mol}^{-1}
$$

现代最精确的方法是通过X射线晶体衍射测量晶体的晶格常数，结合晶体的密度和摩尔质量来计算。这种方法的精度极高，是目前国际单位制中定义阿伏伽德罗常数的基础。

知道了阿伏伽德罗常数，我们可以估算原子的大小。以固态金属为例，假设原子紧密堆积，原子的体积近似等于摩尔体积除以阿伏伽德罗常数。对于典型的金属，原子的直径约为 $10^{-10}$ m，即 1 Å(埃)。这个尺度是原子物理学研究的典型尺度，也是化学键的典型长度。

## 硅基视角：从测量到反演

从计算机科学的角度看，汤姆孙和密立根的实验展示了一种经典的"测量-反演"模式。在汤姆孙的实验中，输入是已知的电场强度和磁场强度，输出是粒子的偏转轨迹，目标是反演出粒子的荷质比。在密立根的实验中，输入是电场强度和油滴的运动状态，输出是油滴的速度，目标是反演出油滴的电荷。

这种模式在现代科学和工程中无处不在。在医学成像中，CT扫描通过测量X射线在不同方向上的吸收来反演人体内部的密度分布。在地球物理勘探中，通过测量地震波的传播时间来反演地下的结构。在机器学习中，通过观察输入输出数据来反演模型的参数。

汤姆孙实验的巧妙之处在于，他通过设计让电场力和磁场力平衡的条件，将一个需要测量两个未知数（$e$ 和 $m$）的问题，转化为只需要测量一个组合量（$e/m$）的问题。这种简化问题的策略在科学研究中非常常见。

密立根实验的巧妙之处则在于利用油滴匀速运动的条件来间接测量难以直接测量的量（油滴质量）。这种"用容易测量的量来间接测量难以测量的量"的方法，是实验物理学的核心技能之一。

让我们用一段代码来模拟密立根油滴实验的数据分析过程。假设我们测量了多个油滴的电荷值，如何从这些数据中提取出基本电荷 $e$ 的值？

```{code-cell} ipython3
:tags: [hide-input]

import numpy as np
import matplotlib.pyplot as plt

# 模拟密立根油滴实验数据
# 假设真实的基本电荷为 e0
e0 = 1.602e-19  # C

# 生成若干个油滴，每个油滴带有 1~10 个电子的电荷
np.random.seed(42)
n_droplets = 50
n_electrons = np.random.randint(1, 11, n_droplets)  # 电子数
# 加入 2% 的测量误差
measurement_error = 0.02
charges = n_electrons * e0 * (1 + measurement_error * np.random.randn(n_droplets))

# 绘制测量结果
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 左图：电荷值分布
axes[0].scatter(range(n_droplets), charges * 1e19, alpha=0.7)
axes[0].set_xlabel('油滴编号')
axes[0].set_ylabel('电荷 (×10⁻¹⁹ C)')
axes[0].set_title('各油滴的电荷测量值')
for n in range(1, 11):
    axes[0].axhline(y=n * e0 * 1e19, color='r', linestyle='--', alpha=0.3)

# 右图：电荷值的最大公约数分析
# 计算所有电荷对之间的差值，寻找最小间隔
charge_diffs = []
sorted_charges = np.sort(charges)
for i in range(len(sorted_charges) - 1):
    diff = sorted_charges[i+1] - sorted_charges[i]
    if diff > 0.5e-19:  # 忽略太小的差值（同一能级的测量误差）
        charge_diffs.append(diff)

axes[1].hist(np.array(charge_diffs) * 1e19, bins=20, edgecolor='black', alpha=0.7)
axes[1].axvline(x=e0 * 1e19, color='r', linestyle='--', label=f'真实值 e = {e0*1e19:.3f}×10⁻¹⁹ C')
axes[1].set_xlabel('相邻电荷差值 (×10⁻¹⁹ C)')
axes[1].set_ylabel('频数')
axes[1].set_title('电荷差值分布（用于确定基本电荷）')
axes[1].legend()

plt.tight_layout()
plt.show()

# 估计基本电荷：使用最小二乘法拟合
# 假设 q_i = n_i * e，用整数规划找最佳的 e
def estimate_e(charges, e_range):
    """通过最小二乘法估计基本电荷"""
    best_e = e_range[0]
    best_residual = np.inf

    for e_test in e_range:
        # 对每个电荷值，找最接近的整数倍
        n_est = np.round(charges / e_test)
        residual = np.sum((charges - n_est * e_test)**2)
        if residual < best_residual:
            best_residual = residual
            best_e = e_test

    return best_e

e_range = np.linspace(1.5e-19, 1.7e-19, 1000)
e_estimated = estimate_e(charges, e_range)
print(f"估计的基本电荷: e = {e_estimated:.4e} C")
print(f"真实值:        e = {e0:.4e} C")
print(f"相对误差:      {abs(e_estimated - e0) / e0 * 100:.2f}%")
```

这段代码模拟了密立根的数据分析过程：从一组带有测量误差的电荷数据中，提取出基本电荷的值。关键的观察是，所有测量到的电荷值都应该是基本电荷的整数倍，因此电荷差值的分布应该在基本电荷附近有一个峰值。

## 本节小结

本节我们回顾了电子发现的历史过程。汤姆孙通过阴极射线实验发现了电子，并测定了电子的荷质比。密立根通过油滴实验精确测定了电子电荷，证明了电荷的量子化。结合这两个实验的结果，我们得到了电子的质量。阿伏伽德罗常数的测定建立了宏观量和微观量之间的桥梁。

电子的发现证明了原子具有内部结构，但原子内部的结构究竟是什么样的？电子带负电，原子整体是电中性的，那么正电荷在哪里？正电荷和电子是如何分布的？这些问题的答案要等到卢瑟福的散射实验才能揭晓。
