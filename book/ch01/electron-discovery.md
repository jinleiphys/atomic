# 1.1 电子的发现与基本性质

## 阴极射线与电子的发现

19世纪后半叶，物理学家们对真空放电现象产生了浓厚的兴趣。当在抽成低压的玻璃管两端施加高电压时，会观察到从阴极发出一种射线，使管壁发出荧光。这种射线被称为阴极射线，它的本质成为当时物理学界激烈争论的焦点。德国物理学家倾向于认为阴极射线是一种类似于光的电磁波动，而英国物理学家则主张它是由带电粒子组成的。

1897年，剑桥大学卡文迪许实验室的约瑟夫·约翰·汤姆孙（Joseph John Thomson）通过一系列精巧的实验，最终解决了这个争论。他的实验思路清晰而有力：如果阴极射线是由带电粒子组成的，那么它应该会被电场和磁场偏转。汤姆孙首先证明了阴极射线确实可以被电场偏转，这一结果看似简单，实际上却需要极高的真空度。在此之前，由于真空管中残余气体的电离作用，电场会被屏蔽，导致偏转效应不明显。汤姆孙改进了抽真空技术，成功观察到了电场对阴极射线的偏转。

汤姆孙接下来进行了一个更为精巧的实验。他让阴极射线同时受到互相垂直的电场和磁场作用，通过调节电场和磁场的强度，可以使两者对粒子的作用力相互抵消，从而让射线不发生偏转。设电场强度为 $E$，磁场强度为 $B$，粒子速度为 $v$，则电场力 $eE$ 与磁场力 $evB$ 平衡的条件是 $eE = evB$，由此可以得到粒子的速度 $v = E/B$。然后，撤去电场只保留磁场，粒子将在洛伦兹力的作用下做圆周运动。根据牛顿第二定律 $evB = mv^2/r$，可以得到粒子的荷质比

$$
\frac{e}{m} = \frac{v}{Br} = \frac{E}{B^2 r}
$$

汤姆孙的实验结果令人震惊。他发现阴极射线粒子的荷质比约为 $1.76 \times 10^{11}$ C/kg，这个数值比当时已知的任何离子的荷质比都要大得多。以氢离子为例，其荷质比约为 $9.6 \times 10^7$ C/kg，比阴极射线粒子小了近两千倍。更重要的是，无论使用什么材料做阴极，无论管中残留什么气体，测得的荷质比都是相同的。这意味着阴极射线粒子是一种普遍存在于所有物质中的基本组成成分。汤姆孙将这种粒子命名为"电子"（electron），这个名称来源于希腊语中的"琥珀"一词，因为古人最早在摩擦琥珀时发现了静电现象。

汤姆孙的发现具有划时代的意义。它首次证明了原子不是不可分割的，而是具有内部结构的。电子从各种不同的原子中被释放出来，说明电子是所有原子的共同组成部分。这个发现不仅改变了人们对物质本质的认识，也开启了探索原子内部结构的新时代。

## 电子电荷的精确测定

汤姆孙的实验测定了电子的荷质比 $e/m$，但要分别确定电子的电荷 $e$ 和质量 $m$，还需要独立测量其中一个量。这个任务由汤姆孙的学生罗伯特·密立根（Robert Millikan）在1909年至1913年间完成，他发展的"油滴实验"成为物理学史上最精巧的实验之一。

密立根实验的基本思想是让带电油滴悬浮在电场中。当油滴受到的电场力恰好与重力平衡时，油滴将静止悬浮。设油滴的电荷为 $q$，质量为 $m_d$，电场强度为 $E$，平衡条件为 $qE = m_d g$。然而，直接测量微小油滴的质量是非常困难的，密立根采用了一个巧妙的方法来解决这个问题。

密立根的方法是观察油滴在无电场时的匀速下落过程。当油滴在空气中下落时，它受到重力和空气阻力的作用。空气阻力由斯托克斯公式给出：$f = 6\pi\eta r v$，其中 $\eta$ 是空气的粘滞系数，$r$ 是油滴半径，$v$ 是下落速度。当油滴达到匀速下落时，重力等于阻力加上浮力：

$$
\frac{4}{3}\pi r^3 \rho g = 6\pi\eta r v_1 + \frac{4}{3}\pi r^3 \rho_0 g
$$

其中 $\rho$ 是油的密度，$\rho_0$ 是空气密度，$v_1$ 是无电场时的匀速下落速度。由此可以求出油滴半径 $r$，进而求出油滴质量。然后施加电场使油滴匀速上升，测量上升速度 $v_2$，根据力的平衡条件可以求出油滴的电荷 $q$。

密立根实验的精妙之处不仅在于测量方法的巧妙设计，更在于对实验细节的精心控制。他使用钟表油代替普通油滴，因为钟表油不易挥发，可以保持油滴大小的稳定。他在密闭容器中进行实验，以避免空气对流的干扰。他使用X射线照射来改变油滴的电荷，从而可以在同一个油滴上多次测量不同电荷值。

密立根对数千个油滴进行了测量，发现一个惊人的规律：所有油滴的电荷都是某个最小值的整数倍。这个最小值就是电子电荷的大小。他得到的结果是 $e = 1.592 \times 10^{-19}$ C，与现代精确值 $e = 1.602 \times 10^{-19}$ C 非常接近。这个实验不仅精确测定了电子电荷，更重要的是证明了电荷的量子化：电荷不能取任意值，只能是基本电荷的整数倍。

结合汤姆孙测得的荷质比和密立根测得的电荷值，可以计算出电子的质量：

$$
m_e = \frac{e}{e/m} = \frac{1.602 \times 10^{-19}}{1.76 \times 10^{11}} = 9.11 \times 10^{-31} \text{ kg}
$$

这个质量只有氢原子质量的约 1/1836，说明电子是一种极轻的粒子。原子的绝大部分质量不在电子身上，而是集中在原子的另一部分——这一部分是什么，要等到卢瑟福的散射实验才能揭晓。

## 阿伏伽德罗常数的测定

阿伏伽德罗常数 $N_A$ 是连接宏观世界和微观世界的重要桥梁。它的定义是：一摩尔任何物质所含的基本单元数目。知道了阿伏伽德罗常数，我们就可以计算单个原子或分子的质量和大小。

历史上，阿伏伽德罗常数的测定有多种方法。最直接的方法之一是利用电解定律。法拉第发现，在电解过程中，沉积或释放一摩尔任何一价物质所需的电量是一个常数，称为法拉第常数 $F$。这个常数的物理意义很明确：它等于一摩尔电子所携带的总电荷，即 $F = N_A e$。法拉第常数可以通过精确的电解实验测定，其值为 $F = 96485$ C/mol。如果已知电子电荷 $e$，就可以计算出阿伏伽德罗常数：

$$
N_A = \frac{F}{e} = \frac{96485}{1.602 \times 10^{-19}} = 6.02 \times 10^{23} \text{ mol}^{-1}
$$

另一种测定阿伏伽德罗常数的方法是通过布朗运动。1905年爱因斯坦发表了关于布朗运动的理论，预言悬浮在液体中的微粒的均方位移与阿伏伽德罗常数有关。佩兰通过精密的显微观测验证了爱因斯坦的理论，并由此测定了阿伏伽德罗常数，这项工作使他获得了1926年的诺贝尔物理学奖。

还有一种更为直接的方法是通过X射线晶体衍射测量晶体的晶格常数，结合晶体的密度和摩尔质量来计算阿伏伽德罗常数。这种方法的精度非常高，是目前国际单位制中定义阿伏伽德罗常数的基础。

知道了阿伏伽德罗常数，我们可以估算原子的大小。以固态金属为例，假设原子紧密堆积，原子的体积近似等于摩尔体积除以阿伏伽德罗常数。对于典型的金属，原子的直径约为 $10^{-10}$ m，即 1 Å（埃）。这个尺度是原子物理学研究的典型尺度，也是化学键的典型长度。

## 硅基视角：从测量到反演

从计算机科学的角度看，汤姆孙和密立根的实验展示了一种经典的"测量-反演"模式。在汤姆孙的实验中，输入是已知的电场强度和磁场强度，输出是粒子的偏转轨迹，目标是反演出粒子的荷质比。在密立根的实验中，输入是电场强度和油滴的运动状态，输出是油滴的速度，目标是反演出油滴的电荷。

这种模式在现代科学和工程中无处不在。在医学成像中，CT扫描通过测量X射线在不同方向上的吸收来反演人体内部的密度分布。在地球物理勘探中，通过测量地震波的传播时间来反演地下的结构。在机器学习中，通过观察输入输出数据来反演模型的参数。

汤姆孙实验的巧妙之处在于，他通过设计让电场力和磁场力平衡的条件，将一个需要测量两个未知数（$e$ 和 $m$）的问题，转化为只需要测量一个组合量（$e/m$）的问题。这种简化问题的策略在科学研究中非常常见。

密立根实验的巧妙之处则在于利用油滴匀速运动的条件来间接测量难以直接测量的量（油滴质量）。这种"用容易测量的量来间接测量难以测量的量"的方法，是实验物理学的核心技能之一。

让我们用一段代码来模拟密立根油滴实验的数据分析过程。假设我们测量了多个油滴的电荷值，如何从这些数据中提取出基本电荷 $e$ 的值？

```{code-cell} ipython3
:tags: [hide-input]

import numpy as np
import matplotlib.pyplot as plt

# 模拟密立根油滴实验数据
# 假设真实的基本电荷为 e0
e0 = 1.602e-19  # C

# 生成若干个油滴，每个油滴带有 1~10 个电子的电荷
np.random.seed(42)
n_droplets = 50
n_electrons = np.random.randint(1, 11, n_droplets)  # 电子数
# 加入 2% 的测量误差
measurement_error = 0.02
charges = n_electrons * e0 * (1 + measurement_error * np.random.randn(n_droplets))

# 绘制测量结果
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 左图：电荷值分布
axes[0].scatter(range(n_droplets), charges * 1e19, alpha=0.7)
axes[0].set_xlabel('油滴编号')
axes[0].set_ylabel('电荷 (×10⁻¹⁹ C)')
axes[0].set_title('各油滴的电荷测量值')
for n in range(1, 11):
    axes[0].axhline(y=n * e0 * 1e19, color='r', linestyle='--', alpha=0.3)

# 右图：电荷值的最大公约数分析
# 计算所有电荷对之间的差值，寻找最小间隔
charge_diffs = []
sorted_charges = np.sort(charges)
for i in range(len(sorted_charges) - 1):
    diff = sorted_charges[i+1] - sorted_charges[i]
    if diff > 0.5e-19:  # 忽略太小的差值（同一能级的测量误差）
        charge_diffs.append(diff)

axes[1].hist(np.array(charge_diffs) * 1e19, bins=20, edgecolor='black', alpha=0.7)
axes[1].axvline(x=e0 * 1e19, color='r', linestyle='--', label=f'真实值 e = {e0*1e19:.3f}×10⁻¹⁹ C')
axes[1].set_xlabel('相邻电荷差值 (×10⁻¹⁹ C)')
axes[1].set_ylabel('频数')
axes[1].set_title('电荷差值分布（用于确定基本电荷）')
axes[1].legend()

plt.tight_layout()
plt.show()

# 估计基本电荷：使用最小二乘法拟合
# 假设 q_i = n_i * e，用整数规划找最佳的 e
def estimate_e(charges, e_range):
    """通过最小二乘法估计基本电荷"""
    best_e = e_range[0]
    best_residual = np.inf

    for e_test in e_range:
        # 对每个电荷值，找最接近的整数倍
        n_est = np.round(charges / e_test)
        residual = np.sum((charges - n_est * e_test)**2)
        if residual < best_residual:
            best_residual = residual
            best_e = e_test

    return best_e

e_range = np.linspace(1.5e-19, 1.7e-19, 1000)
e_estimated = estimate_e(charges, e_range)
print(f"估计的基本电荷: e = {e_estimated:.4e} C")
print(f"真实值:        e = {e0:.4e} C")
print(f"相对误差:      {abs(e_estimated - e0) / e0 * 100:.2f}%")
```

这段代码模拟了密立根的数据分析过程：从一组带有测量误差的电荷数据中，提取出基本电荷的值。关键的观察是，所有测量到的电荷值都应该是基本电荷的整数倍，因此电荷差值的分布应该在基本电荷附近有一个峰值。

## 本节小结

本节我们回顾了电子发现的历史过程。汤姆孙通过阴极射线实验发现了电子，并测定了电子的荷质比。密立根通过油滴实验精确测定了电子电荷，证明了电荷的量子化。结合这两个实验的结果，我们得到了电子的质量。阿伏伽德罗常数的测定建立了宏观量和微观量之间的桥梁。

电子的发现证明了原子具有内部结构，但原子内部的结构究竟是什么样的？电子带负电，原子整体是电中性的，那么正电荷在哪里？正电荷和电子是如何分布的？这些问题的答案要等到卢瑟福的散射实验才能揭晓。
